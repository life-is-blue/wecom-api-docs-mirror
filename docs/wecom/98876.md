# 获取网络研讨会报名信息

获取已报名观众数量和报名观众答题详情。

* 会议未开启报名时会返回未开启报名错误。

**请求方式：** POST（**HTTPS**）
**请求地址：** https://qyapi.weixin.qq.com/cgi-bin/meeting/webinar/enroll/list?access\_token=ACCESS\_TOKEN

**请求包体：**

```json
{
	"meetingid": "MEETINGID1",
	"status": 1,
	"cursor": "CURSOR",
	"limit": 20
}
```

**参数说明：**

| 参数 | 必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| access\_token | 是 | string | 调用接口凭证。获取方法查看“[获取access\_token](./15074.md)” |
| meetingid | 是 | string | 网络研讨会 ID |
| status | 否 | uint32 | 审批状态筛选字段，默认返回全部。审批状态： 0：全部。 1：待审批。 2：已拒绝。 3：已批准。 |
| cursor | 否 | string | 分页查询用，将上一个请求返回的next\_cursor字段传入。第一次查询时可不传值 |
| limit | 否 | uint32 | 分页大小，最大50条。默认值为50 |

**权限说明**

* 仅配置在“可调用接口的应用”列表中的自建应用可调用
* 仅允许获取该应用创建的网络研讨会的数据

**返回结果：**

```javascript
{
	"errcode": 0,
	"errmsg": "ok",
	"has_more": false,
	"next_cursor": "CURSOR",
	"enroll_list":[{
        "enroll_id":1386442,
        "enroll_time":"2023-03-23 10:00:00",
        "enroll_source_type":2,
        "nick_name":"ccc",
        "status":3,
        "userid":"USERID",
        "tmp_openid":"MSOPENID",
        "enroll_code":"1111111",
		"answer_list": [{
			"answer_content": ["A"],
			"is_required": 1,
			"question_num": 1,
			"question_title": "testqus",
			"question_type": 1,
			"special_type": 1
		}]
    }]
}
```

**参数说明**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| errcode | int32 | 返回码 |
| errmsg | string | 对返回码的文本描述内容 |
| has\_more | bool | 是否还有待拉取的成员列表 |
| next\_cursor | string | 分页用，下一次拉取列表将该字段填入cursor字段 |
| enroll\_list | object[] | 当前页的报名列表。详见Enroll。 |

**Enroll 说明**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| enroll\_id | string | 报名 ID |
| enroll\_time | string | 报名时间（utc +8，非时间戳） |
| enroll\_source\_type | uint32 | 报名来源： 1：成员手动报名 2：批量导入报名 |
| nick\_name | string | 昵称。若通过手机号导入报名且未设置昵称，则该字段显示手机号 |
| status | uint32 | 报名状态： 1：待审批 2：已拒绝 3：已批准 |
| userid | string | 为企业内成员时返回userid |
| tmp\_openid | string | 当场会议的成员临时 ID |
| enroll\_code | string | 报名码，用于电话入会的凭证 |
| answer\_list | object[] | 答题对象列表，详见Answer。 |

**Answer 说明**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| answer\_content | string[] | 回答内容：单选/简答只有一个元素，多选会有多个 |
| is\_required | uint32 | 是否必填： 1：否 2：是 |
| question\_num | uint32 | 问题编号，1,2,3...等形式 |
| question\_title | string | 问题标题 |
| question\_type | uint32 | 问题类型： 1：单选 2：多选 3：简答 |
| special\_type | uint32 | 特殊问题类型： 1：无 2：手机号 3：邮箱 4：姓名 5：公司名称 **说明：**目前特殊问题均为简答题 |
