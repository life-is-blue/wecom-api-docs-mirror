请求方式：GET（HTTPS）
请求地址：https://qyapi.weixin.qq.com/cgi-bin/department/delete?access_token=ACCESS_TOKEN&id=ID

 

参数说明 ：

参数必须说明
access_token是调用接口凭证
id是部门id。（注：不能删除根部门；不能删除含有子部门、成员的部门）

 

权限说明：

应用须拥有指定部门的管理权限。
第三方仅通讯录应用可以调用。

返回结果：

{
   "errcode": 0,
   "errmsg": "deleted"
}

参数说明：

参数说明
errcode返回码
errmsg对返回码的文本描述内容
