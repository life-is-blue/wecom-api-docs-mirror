# 获取网络状态

## ww.getNetworkType([params])

> 兼容性：企业微信 iOS、Android，微信

### 功能描述

获取网络状态。

```ts
ww.getNetworkType()
```

### 参数说明

#### params: Object

|  | 属性 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
|  | success | Function | 否 | 成功回调 |
|  | fail | Function | 否 | 失败回调 |
|  | cancel | Function | 否 | 取消回调 |
|  | complete | Function | 否 | 完成回调 |

### 示例代码

```javascript

    }
});
```
