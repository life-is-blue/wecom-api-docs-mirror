# 客户同意进行聊天内容存档事件回调

[配置了客户联系功能](#13473/%E5%BC%80%E5%A7%8B%E5%BC%80%E5%8F%91)的成员添加外部联系人同意进行聊天内容存档时，回调该事件。

> 回调的json包序列化为字符串传给注册的回调函数data字段

请求示例：

```javascript
{
    "event_type": "chat_archive_audit_approved_single",
    "timestamp": 1408091189,
    "chat_archive_audit_approved": {
        "userid": "xxxxxxx",
        "external_userid": "zzzzz",
				"chatid":"xxx"
    }
}
```

参数说明：

| 参数 | 说明 |
| --- | --- |
| event\_type | 事件类型 当客户在单聊中同意存档时，该字段值为chat\_archive\_audit\_approved\_single 当客户在群聊中同意存档时，该字段值为chat\_archive\_audit\_approved\_room |
| timestamp | 时间戳 |
| userid | 单聊时返回，企业服务人员的UserID |
| external\_userid | 外部联系人的userid，注意不是企业成员的账号 |
| chatid | 群聊时返回，所在群聊的ChatId |
