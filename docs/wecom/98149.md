# 获取会议详情

该接口用于获取指定会议的详情内容。

**请求方式：** POST（**HTTPS**）
**请求地址：** https://qyapi.weixin.qq.com/cgi-bin/meeting/get\_info?access\_token=ACCESS\_TOKEN

**请求包体：**

```json
{
   "meetingid": "XXXXXXXXX",
   "meeting_code":"meetingcodexxx",
   "sub_meetingid":"submeeting"
}
```

**参数说明：**

| 参数 | 必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| access\_token | 是 | string | 调用接口凭证。获取方法查看“[获取access\_token](./15074.md)” |
| meetingid | 否 | string | 会议id。`注意：meetingid和meeting_code必须填一个` |
| meeting\_code | 否 | string | 入会码。`注意：meetingid和meeting_code必须填一个` |
| sub\_meetingid | 否 | string | 周期性会议子会议id |

**权限说明：**

* 只能拉取该应用创建的会议
* 自建应用需要配置在“可调用接口的应用”列表

**参数说明：**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| errcode | int32 | 返回码 |
| errmsg | string | 对返回码的文本描述内容 |
| admin\_userid | string | 会议管理员的userId |
| title | string | 会议的标题，最大40个字节 |
| meeting\_start | uint32 | 会议开始时间的unix时间戳 |
| meeting\_duration | uint32 | 会议时长 |
| description | string | 会议的描述，最大600字节 |
| location | string | 会议地点,最多128个字符 |
| main\_department | uint32 | 发起人所在部门 |
| status | uint32 | 会议的状态。 1：待开始 2：会议中 3：已结束 4：已取消 5：已过期 |
| meeting\_type | uint32 | 会议类型。 0：一次性会议 1：周期性会议 2：微信专属会议 3：Rooms 投屏会议 5：个人会议号会议 6：网络研讨会 |
| attendees | object[] | 参会成员。 |
| attendees.member | object | 企业内部成员 |
| attendees.member.userid | string | 企业内部成员的userid |
| attendees.member.status | uint32 | 与会状态。 1为已参与 2为未参与。 |
| attendees.member.first\_join\_time | uint32 | 参会人首次加入会议时间的unix时间戳 |
| attendees.member.last\_quit\_time | uint32 | 参会人最后一次离开会议时间的unix时间戳 |
| attendees.member.total\_join\_count | uint32 | 参会人入会次数 |
| attendees.member.cumulative\_time | uint32 | 参会人累计参会时长，单位为秒 |
| attendees.tmp\_external\_user | object | 会中参会的外部联系人 `注意：微信入会的用户不会返回` |
| attendees.tmp\_external\_user.tmp\_external\_userid | string | 会中入会的外部用户临时id。同一个用户在不同会议中返回的该id不一致。 |
| attendees.tmp\_external\_user.status | uint32 | 与会状态。 1为已参与 2为未参与 |
| attendees.tmp\_external\_user.first\_join\_time | uint32 | 参会人首次进入会议时间的unix时间戳 |
| attendees.tmp\_external\_user.last\_quit\_time | uint32 | 参会人最后一次离开会议时间的unix时间戳 |
| attendees.tmp\_external\_user.total\_join\_count | uint32 | 参会人入会次数 |
| attendees.tmp\_external\_user.cumulative\_time | uint32 | 参会人累计参会时长，单位为秒 |
| guests | object | 会议嘉宾列表，详见Guest |
| settings | object | 会议配置，详见Settings |
| reminders | object | 重复会议相关配置，详见Reminders |
| meeting\_code | string | 会议号 |
| meeting\_link | string | 入会链接 |
| has\_vote | bool | 是否有投票（会议创建人和主持人才有权限查询）。 |
| sub\_meetings | object | 周期性子会议列表，详见SubMeeting |
| has\_more\_sub\_meeting | uint32 | 是否还有更多子会议特例。 0：无更多 1：有更多子会议特例 |
| remain\_sub\_meetings | uint32 | 剩余子会议场数 |
| current\_sub\_meetingid | string | 当前子会议ID（进行中/即将开始） |
| sub\_repeat\_list | object[] | 周期性会议分段信息。企业微信客户端可以对周期性会议中某一场子会议进行『修改此会议』和『修改此及后续会议』操作，修改之后会议可能会被分裂成不同的分段，每个分段有不同的重复规则，可以通过该字段获取所有的分段信息，详见SubRepeatInfo |

**Guest说明：**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| area | string | 国家/地区代码（例如：中国传86，不是+86，也不是0086）。 |
| phone\_number | string | 手机号。 |
| guest\_name | string | 会议嘉宾姓名。 |

**Settings说明：**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| password | bool | 入会密码 |
| enable\_waiting\_room | bool | 是否开启等候室。 true：开启等候室 false：不开启等候室 |
| allow\_enter\_before\_host | bool | 是否允许成员在主持人进会前加入。 true：允许 false：不允许 |
| remind\_scope | uint32 | 会议开始时来电提醒方式。 1：不提醒  2：仅提醒主持人  3：提醒所有成员入  4：指定部分人响铃 |
| enable\_enter\_mute | uint32 | 是否开启成员入会静音选项。 1：开启 0：关闭 2：超过6人后自动开启静音 |
| allow\_unmute\_self | bool | 是否允许参会者取消静音。 true：允许 false：不允许 |
| watermark\_type | uint32 | 水印样式。 0：单排 1：多排 |
| auto\_record\_type | string | 自动会议录制类型。 none：禁用，表示不开启自动会议录制 local：本地录制，表示主持人入会后自动开启本地录制 cloud：云录制，表示主持人入会后自动开启云录制 |
| attendee\_join\_auto\_record | bool | 是否在有参会成员入会时立即开启云录制 |
| enable\_host\_pause\_auto\_record | bool | 是否允许主持人暂停或者停止云录制 |
| enable\_doc\_upload\_permission | bool | 是否允许成员上传文档 |
| enable\_enroll | bool | 是否激活报名。 |
| enable\_host\_key | bool | 是否开启主持人密钥。 true：开启 false：关闭 |
| host\_key | string | 主持人密钥。 |
| allow\_external\_user | bool | 是否允许企业外部成员入会。 true：所有成员可入会 false：仅企业内部成员可入会 |
| enable\_screen\_watermark | bool | 是否开启屏幕水印。 true：开启 false：不开启 |
| hosts | object | 会议主持人人列表 |
| hosts.userid | string[] | 主持人userid |
| current\_hosts | object | 会议当前主持人列表 |
| current\_host.userid | string[] | 当前主持人userid |
| co\_hosts | object | 联席主持人列表 |
| co\_hosts.userid | string[] | 联席主持人userid |
| ring\_users | object | 指定响铃的成员列表。 |
| ring\_users.userid | string[] | 指定响铃的成员userid |

**Reminders说明：**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| is\_repeat | uint32 | 是否是周期性会议。 1：周期性会议  0：非周期性会议 |
| repeat\_type | uint32 | 重复类型。 0 - 每日 1 - 每周 2 - 每月 7 - 工作日 |
| is\_custom\_repeat | uint32 | 是否自定义重复设置。 0-否 1-是 |
| repeat\_interval | uint32 | 周期间隔 该字段随repeat\_type不同而含义不同 例如： repeat\_interval指定为3，repeat\_type指定为每周重复，那么每3周重复一次； repeat\_interval指定为3，repeat\_type指定为每月重复，那么每3个月重复一次 |
| repeat\_day\_of\_week | uint32[] | 每周周几重复 取值范围：1 ~ 7，分别表示周一至周日 |
| repeat\_day\_of\_month | uint32[] | 每月哪几天重复 取值范围：1 ~ 31，分别表示1~31号 |
| repeat\_until\_type | uint32 | 周期性会议结束类型。 0：按日期结束重复 1：按次数结束重复 |
| repeat\_until\_count | uint32 | 周期会议限定次数 |
| repeat\_until | uint32 | 周期会议结束时刻。repeat\_until\_type=0时该字段才返回 |
| remind\_before | uint32[] | 会议开始前多久提醒成员，相对于meeting\_start前的秒数。 0：会议开始时提醒 300：5分钟前提醒 900：15分钟前提醒 3600：一小时前提醒 86400：一天前提醒 |

**SubMeeting：**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| sub\_meetingid | string | 子会议 ID。 |
| status | uint32 | 子会议状态。 0：默认（存在） 1：已删除 |
| start\_time | uint32 | 子会议开始时间（UTC 秒） |
| end\_time | uint32 | 子会议结束时间（UTC 秒） |
| title | string | 子会议标题 |
| repeat\_id | string | 周期性会议分段ID，通过该字段可以关联子会议所属的分段 |

**SubRepeatInfo：**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| repeat\_id | string | 分段ID |
| repeat\_type | uint32 | 重复类型。 0 - 每日 1 - 每周 2 - 每月 7 - 工作日 |
| is\_custom\_repeat | uint32 | 是否自定义重复设置。 0-否 1-是 |
| repeat\_interval | uint32 | 周期间隔 该字段随repeat\_type不同而含义不同 例如： repeat\_interval指定为3，repeat\_type指定为每周重复，那么每3周重复一次； repeat\_interval指定为3，repeat\_type指定为每月重复，那么每3个月重复一次 |
| repeat\_day\_of\_week | uint32[] | 每周周几重复 取值范围：1 ~ 7，分别表示周一至周日 |
| repeat\_day\_of\_month | uint32[] | 每月哪几天重复 取值范围：1 ~ 31，分别表示1~31号 |
| repeat\_until\_type | uint32 | 周期性会议结束类型。 0：按日期结束重复 1：按次数结束重复 |
| repeat\_until\_count | uint32 | 分段的重复截止次数，repeat\_until\_type=1时返回 |
| repeat\_until | uint32 | 分段的重复截止时间，repeat\_until\_type=0时该字段才返回 |
