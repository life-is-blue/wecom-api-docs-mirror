# 停止企业群发

企业和第三方应用可调用此接口，停止无需成员继续发送的企业群发
**请求方式**:**POST**(**HTTPS**)

**请求地址:**https://qyapi.weixin.qq.com/cgi-bin/externalcontact/cancel\_groupmsg\_send?access\_token=ACCESS\_TOKEN

**请求示例**

```javascript
{
    "msgid": "msgGCAAAXtWyujaWJHDDGi0mACAAAA"
}
```

**参数说明**:

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access\_token | 是 | 调用接口凭证 |
| msgid | 是 | 群发消息的id，通过[获取群发记录列表](#%E8%8E%B7%E5%8F%96%E7%BE%A4%E5%8F%91%E8%AE%B0%E5%BD%95%E5%88%97%E8%A1%A8)接口返回 |

**权限说明**:

* 企业需要使用配置到“[可调用应用](./92109.md#%E5%BC%80%E5%A7%8B%E5%BC%80%E5%8F%91)”列表中的自建应用secret所获取的accesstoken来调用（[accesstoken如何获取？](#10013/%E7%AC%AC%E4%B8%89%E6%AD%A5%EF%BC%9A%E8%8E%B7%E5%8F%96access_token)）。
* 第三方应用调用需要企业授权**客户联系**下**群发消息给客户和客户群**的权限；营销获客类应用需要拥有“客户联系权限->消息推送权限->群发消息给客户和客户群”权限。

**返回结果**:

```javascript
{
    "errcode": 0,
    "errmsg": "ok"
}
```

**参数说明**:

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述内容 |

> 注意，此接口无法撤回已经群发给客户的消息。
