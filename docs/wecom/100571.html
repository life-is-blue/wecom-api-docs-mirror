    • ww.onBeaconUpdate(callback)

    兼容性：企业微信

    功能描述

    监听 iBeacon 设备的更新事件。

    ww.onBeaconUpdate(function(event) {
  console.log(event)
})

    参数说明

    callback: Function

    参数

    event: Object

    属性类型必填说明
    beaconsObject[]是

    当前搜寻到的所有 iBeacon 设备列表

    属性类型必填说明
    uuidstring是

    iBeacon 设备广播的 uuid

    majorstring是

    iBeacon 设备的主 id

    minorstring是

    iBeacon 设备的次 id

    proximitynumber是

    表示设备距离的枚举值, 0 信号太弱不足以计算距离, 或非 iOS 设备; 1 十分近; 2 比较近; 3 远;

    accuracynumber是

    iBeacon 设备的距离

    rssinumber是

    表示设备的信号强度

    旧版jweixin调用

    示例代码

    wx.onBeaconUpdate(function(event) {
  console.log(event)
})
