# 获取个人居民上报数据统计

**请求方式：** POST（**HTTPS**）
**请求地址：** https://qyapi.weixin.qq.com/cgi-bin/report/resident/get\_user\_status?access\_token=ACCESS\_TOKEN

**请求包体：**

```json
{
    "userid": "zhangsan"
}
```

**参数说明：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access\_token | 是 | 调用接口凭证。“[获取access\_token](https://work.weixin.qq.com/api/doc/90001/90143/90605)” |
| userid | 是 | 成员的userId |

**权限说明：**

| 应用类型 | 权限要求 |
| --- | --- |
| 自建应用 | 配置到「[居民上报 - 可调用接口的应用](./93513.md#%E9%85%8D%E7%BD%AE%E5%8F%AF%E8%B0%83%E7%94%A8%E6%8E%A5%E5%8F%A3%E7%9A%84%E5%BA%94%E7%94%A8)」中 |
| 代开发应用 | 暂不支持 |
| 第三方应用 | 暂不支持 |

*注：* 从2023年12月1日0点起，不再支持通过系统应用secret调用接口，存量企业暂不受影响 [查看详情](https://developer.work.weixin.qq.com/document/51165)

* 成员必须在应用可见范围内

**返回结果：**

```json
{
   "errcode": 0,
   "errmsg": "ok",
   "processing": 1,
   "added_today": 1,
   "solved_today": 1,
   "pending": 1
}
```

**参数说明：**

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述内容 |
| processing | 办理中 |
| added\_today | 今日上报 |
| solved\_today | 今日办结 |
| pending | 待受理 |
