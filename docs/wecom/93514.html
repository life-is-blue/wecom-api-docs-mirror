请求方式： GET（HTTPS）
请求地址： https://qyapi.weixin.qq.com/cgi-bin/report/resident/get_grid_info?access_token=ACCESS_TOKEN

参数说明：

参数必须说明
access_token是调用接口凭证。“获取access_token”

权限说明：

应用类型权限要求
自建应用配置到「居民上报 - 可调用接口的应用」中
代开发应用暂不支持
第三方应用暂不支持

注： 从2023年12月1日0点起，不再支持通过系统应用secret调用接口，存量企业暂不受影响 查看详情

返回结果：

{
   "errcode": 0,
   "errmsg": "ok",
   "grid_list":[
      {
         "grid_id": "grid_id",
         "grid_name": 1,
         "grid_admin": [
            "zhangsan",
            "lisi"
         ]
      }
   ]
}

参数说明：

参数说明
errcode返回码
errmsg对返回码的文本描述内容
grid_list.grid_id网格 ID
grid_list.grid_name网格名称
grid_list.grid_admin网格管理员 userId 列表
