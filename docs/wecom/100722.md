# 保存选择的选项

## ww.saveApprovalSelectedItems(params)

> 兼容性：企业微信 4.0.18 开始支持

### 功能描述

保存用户选择的审批选项。

用户在网页中修改审批选项时，调用该接口保存用户的选择。

```ts
ww.saveApprovalSelectedItems({
  key: 'key',
  selectedData: [
    {
      key: 'item-1',
      value: '选项1'
    },
    {
      key: 'item-2',
      value: '选项2'
    }
  ]
})
```

### 使用限制

* 本接口必须使用应用身份进行注册
* 应用必须具有审批权限

### 使用说明

* 接口仅用于审批设置外部选项场景，请勿用作其他场景
* 网页应该做好深色模式适配

}, (res) => {
    if (res.err_msg === 'saveApprovalSelectedItems:ok') {
        // 保存成功
    }
});
