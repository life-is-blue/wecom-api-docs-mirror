    • 用于向指定页面中批量添加内容块。

    请求方式：POST（HTTPS）
    请求地址：https://qyapi.weixin.qq.com/cgi-bin/wedoc/smartdoc/add_blocks?access_token=ACCESS_TOKEN

    请求包体

    {
    "docid": "DOC_ID",
    "page_id": "PAGE_ID",
    "blocks": [
        {
            "type": "BLOCK_TYPE_TEXT",
            "title": "Hello World",
            "parent_id": "PARENT_BLOCK_ID",
            "after_id": "AFTER_BLOCK_ID",
            "props": {}
        }
    ]
}

    参数说明

    参数类型是否必须说明
    docidstring是智能文档的文档 id，可通过 新建文档 接口创建
    page_idstring是页面的id
    blocksobject[](BlockInfo)是需要添加的 Block 列表
    blocks[].typestring是Block 类型，参见 BlockType
    blocks[].titlestring否Block 的文本内容
    blocks[].parent_idstring否父节点 Block ID
    blocks[].after_idstring否插入位置，表示排在哪个 Block 之后，为空表示插入到最前
    blocks[].childrenstring[]否子节点 ID 列表
    blocks[].propsobject否Block 属性

     

    权限说明

    • 自建应用需配置到"可调用应用"列表中的应用secret所获取的accesstoken来调用
    • 第三方应用需具有"文档"权限
    • 代开发自建应用需具有"文档"权限

    返回示例

    {
    "errcode": 0,
    "errmsg": "ok",
    "blocks": [
        {
            "id": "BLOCK_ID",
            "type": "BLOCK_TYPE_TEXT",
            "title": "Hello World",
            "parent_id": "PARENT_BLOCK_ID",
            "after_id": "AFTER_BLOCK_ID",
            "children": [],
            "props": {}
        }
    ]
}


    返回参数说明

    参数类型说明
    errcodeint32错误码
    errmsgstring错误码说明
    blocksobject[](BlockInfo)添加成功后返回的 Block 列表（含生成的 ID）

    BlockInfo

    参数类型说明
    idstringBlock的唯一标识ID
    typestringBlock类型，参见 BlockType
    titlestringBlock内容
    parent_idstring父节点ID
    after_idstring后一个兄弟节点ID，为空表示插入到最前
    childrenstring[]子节点ID列表
    propsobject(BlockProps)Block属性

    Block 属性定义

    TextBlockProps - 文本属性

    字段类型说明
    alignuint32块级对齐，参见 TextAlign
    text_alignuint32文本对齐，参见 TextAlign
    block_colorstring文本背景色，参见 BlockColor

    ImageBlockProps - 图片属性

    字段类型说明
    urlstring图片地址
    widthdouble缩放后宽度
    heightdouble缩放后高度
    strokebool是否有图片描边

    FileBlockProps - 文件属性

    字段类型说明
    file_idstring微盘文件ID

    LinkBlockProps - 链接属性

    字段类型说明
    link_urlstring链接地址
    link_namestring链接名称
    link_descriptionstring链接描述

    TableBlockProps - 表格属性

    字段类型说明
    cell_positionsobject[](TableCellMerge)单元格合并信息
    enable_row_headerbool是否有行标题
    enable_column_headerbool是否有列标题

    SmartSheetViewBlockProps - 数据表视图属性

    字段类型说明
    doc_idstring数据表 docid
    table_idstring数据表 id
    view_idstring视图 id
    table_block_idstring数据表的 blockid
    enable_table_titlebool视图标题显示
    enable_add_rowbool显示添加记录按钮

    ColumnListProps - 分栏属性

    字段类型说明
    column_numuint32分栏数量，取值范围 [2, 4]，越界自动 clamp 到边界，缺省/0 取最小值 2

    HighlightBlockProps - 背景属性

    字段类型说明
    background_image_urlstring背景图链接
    extend_backgroundbool是否扩展背景（背景图是否撑满整个块区域）
    block_colorstring块背景色，参见 BlockColor
    border_colorstring边框颜色，参见 BorderColor

    CodeBlockProps - 代码属性

    字段类型说明
    code_languageobject(CodeLanguage)代码语言
    code_wrapbool是否自动换行

    TodoBlockProps - 待办属性

    字段类型说明
    checkedbool是否选中（待办事项是否已完成）

    TextAlign - 文本对齐

    枚举值说明
    TEXT_ALIGN_UNSPECIFIED未指定
    TEXT_ALIGN_LEFT左对齐
    TEXT_ALIGN_CENTER居中对齐
    TEXT_ALIGN_RIGHT右对齐
    TEXT_ALIGN_JUSTIFY两端对齐
