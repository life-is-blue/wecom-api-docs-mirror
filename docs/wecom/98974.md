# 查询申请单状态

> 通过这个接口查询已提交的申请单状态，只能使用该应用本身提交的申请单号
> 使用[提交创建对外收款账户的申请单](#47983/%E6%8F%90%E4%BA%A4%E5%88%9B%E5%BB%BA%E5%AF%B9%E5%A4%96%E6%94%B6%E6%AC%BE%E8%B4%A6%E6%88%B7%E7%9A%84%E7%94%B3%E8%AF%B7%E5%8D%95)接口中填写的out\_request\_no来查询

**请求方式：**POST(**HTTPS**)
**请求地址：**https://qyapi.weixin.qq.com/cgi-bin/miniapppay/get\_applyment\_status?access\_token=ACCESS\_TOKEN

**权限说明：**
调用的应用需要满足如下的权限，且只允许获取由应用本身提交的申请单

| 应用类型 | 权限要求 |
| --- | --- |
| 自建应用 | 配置到「[对外收款- 可调用接口的应用](./93665.md#%E9%85%8D%E7%BD%AE%E5%8F%AF%E8%B0%83%E7%94%A8%E6%8E%A5%E5%8F%A3%E7%9A%84%E5%BA%94%E7%94%A8)」中 |
| 代开发应用 | 暂不支持 |
| 第三方应用 | 暂不支持 |

*注：* 从2023年12月1日0点起，不再支持通过系统应用secret调用接口，存量企业暂不受影响 [查看详情](https://developer.work.weixin.qq.com/document/51165)

**请求包体：**

```javascript
{
	"out_request_no":"xxxxx"
}
```

**参数说明：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access\_token | 是 | 调用接口凭证 |
| out\_request\_no | 是 | 业务申请编号，长度限制为1~32个字符，在[提交创建对外收款账户的申请单](#47983/%E6%8F%90%E4%BA%A4%E5%88%9B%E5%BB%BA%E5%AF%B9%E5%A4%96%E6%94%B6%E6%AC%BE%E8%B4%A6%E6%88%B7%E7%9A%84%E7%94%B3%E8%AF%B7%E5%8D%95)中提交 |

**返回数据：**

```javascript
{
	"errcode":0,
	"errmsg":"ok",
	"status":
	{
		"applyment_state":"xxxxx",
		"applyment_state_desc":"xxxxx",
		"sign_state":"xxxxx",
		"sign_url":"xxxxx",
		"sub_mchid":"xxxxx",
		"audit_detail": [
			{
				"param_name":"xxxxx",
				"reject_reason":"xxxxx"
			},
			{
				"param_name":"xxxxx",
				"reject_reason":"xxxxx"
			}
		],
		"account_validation":
		{
			"account_name":"xxxxx",
			"account_no":"xxxxx",
			"pay_amount":0,
			"destination_account_number":"xxxxx",
			"destination_account_name":"xxxxx",
			"destination_account_bank":"xxxxx",
			"city":"xxxxx",
			"remark":"xxxxx",
			"deadline":"xxxxx",
		},
		"legal_validation_url":"xxxxx"
	},
	"apply_state":1,
	"real_sign_state":2,
	"reject_reason":"xxxxx"
}
```

**参数说明：**

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述 |
| status | 申请单的具体状态，参考[申请单状态参数说明](#status) |
| apply\_state | 申请单当前所处阶段，对应关系参考[申请阶段对应关系](#apply_state) |
| real\_sign\_state | 当前签约阶段，对应关系参考[签约阶段对应关系](#real_sign_state) |
| reject\_reason | 驳回理由 |

**申请单状态参数说明：**

| 参数 | 说明 |
| --- | --- |
| applyment\_state | 申请状态枚举值参考[申请状态枚举值](#applyment_state) |
| applyment\_state\_desc | 申请状态描述 |
| sign\_state | 签约状态枚举值参考[签约状态枚举值](#wx_sign_state) |
| sign\_url | 签约链接1、当申请状态为NEED\_SIGN 或 签约状态为UNSIGNED时返回，该链接为永久有效； 2、申请单中的超级管理者，需用已实名认证的微信扫码打开，完成签约。 |
| sub\_mchid | 电商平台二级商户号当申请状态为NEED\_SIGN或FINISH时才返回。 |
| audit\_detail | 驳回原因详情各项资料的审核情况。当申请状态为REJECTED或 FROZEN时才返回。 |
| audit\_detail.param\_name | 参数名称提交申请单的资料项名称。 |
| audit\_detail.reject\_reason | 驳回原因提交资料项被驳回原因。 |
| account\_validation | 汇款账户验证信息当签约阶段字段（real\_sign\_state字段，注意不是status字段下的sign\_state字段）的值为2（即已签约）时才有可能返回。 当申请状态为ACCOUNT\_NEED\_VERIFY 时有返回，可根据指引汇款，完成账户验证。 参考[汇款账户验证信息参数说明](#account_validation) |
| legal\_validation\_url | 法人验证链接当签约阶段字段（real\_sign\_state字段，注意不是status字段下的sign\_state字段）的值为2（即已签约）时才有可能返回。 1、当申请状态为ACCOUNT\_NEED\_VERIFY，且通过系统校验的申请单，将返回链接。 2、建议将链接转为二维码展示，让商户法人用微信扫码打开，完成账户验证。 注：商户申请单进入审核状态后，微信侧会校验法人证件号码是否跟营业执照匹配，若匹配，返回该字段 ; 若不匹配，不支持法人扫码验证，不返回该字段。 |

**申请状态枚举值：**

| 参数 | 对应状态 | 参数 | 对应状态 |
| --- | --- | --- | --- |
| CHECKING | 资料校验中 | NEED\_SIGN | 待签约 |
| ACCOUNT\_NEED\_VERIFY | 待账户验证 | FINISH | 完成 |
| AUDITING | 审核中 | FROZEN | 已冻结 |
| REJECTED | 已驳回 | CANCELED | 已作废 |

**签约状态枚举值：**

| 参数 | 对应状态 |
| --- | --- |
| UNSIGNED | 未签约。该状态下，电商平台可查询获取签约链接，引导二级商户的超级管理员完成签约 |
| SIGNED | 已签约。指二级商户的超级管理员已完成签约。注意：若申请单被驳回，商户修改了商户主体名称、法人名称、超级管理员信息、主体类型等信息，则需重新签约 |
| NOT\_SIGNABLE | 不可签约。该状态下，暂不支持超级管理员签约。一般为申请单处于已驳回、已冻结、机器校验中状态，无法签约 |

**汇款账户验证信息参数说明：**

| 参数 | 说明 |
| --- | --- |
| account\_name | 付款户名需商户使用该户名的账户进行汇款。 |
| account\_no | 付款卡号结算账户为对私时会返回，商户需使用该付款卡号进行汇款。 |
| pay\_amount | 汇款金额需要汇款的金额(单位：分)。 |
| destination\_account\_number | 收款卡号收款账户的卡号 |
| destination\_account\_name | 收款户名destination\_account\_name |
| destination\_account\_bank | 开户银行收款账户的开户银行名称。 |
| city | 省市信息收款账户的省市。 |
| remark | 备注信息商户汇款时，需要填写的备注信息。 |
| deadline | 汇款截止时间请在此时间前完成汇款。 |

**申请阶段对应关系：**

| 参数 | 对应关系 | 参数 | 对应关系 |
| --- | --- | --- | --- |
| 0 | 初始状态 | 4 | 绑定失败 |
| 1 | 申请中 | 5 | 未申请 |
| 2 | 绑定成功 | 6 | 待法人验证 |
| 3 | 已撤销申请 |  |  |

**签约阶段对应关系：**

| 参数 | 对应关系 |
| --- | --- |
| 0 | 不可签约 |
| 1 | 未签约 |
| 2 | 已签约 |
