# 回调通知

### 概述

企业购买文件内容存档后，需要配置下面两项来开启存档的回调通知能力：
1. 设置存档范围
2. 添加调用接口的应用（应用需要设置接收事件的服务器、可信 IP 地址）

配置后，企业微信会将特定的事件推送给微盘存档可调用接口的应用配置的`回调URL`。
接收并解析事件的方法见：[接收事件](#12977)

### 授权空间变更事件

授权空间变更的时候会触发该事件，授权空间变更有如下情况
1. 授权
- 成员被管理员分配高级功能后，自动授权（自己上传文件、他人继承给自己文件的共享空间被默认授权）
- 成员有了新的自动授权空间：（新建共享空间并上传或被继承文件、加入他人共享空间并上传或被继承文件，该空间被自动授权）
- 成员手动授权
2. 取消授权
- 授权空间被解散
- 成员退出授权空间
- 成员手动取消授权

企业收到该事件后，可以通过[获取成员授权空间](#61812)接口获取成员最新的授权空间情况

示例

```javascript
<xml>
   <ToUserName><![CDATA[toUser]]></ToUserName>
   <FromUserName><![CDATA[fromUser]]></FromUserName>
   <CreateTime>1348831860</CreateTime>
   <MsgType><![CDATA[event]]></MsgType>
   <Event><![CDATA[wedrive_archive_space_change]]></Event>
   <ChangeType><![CDATA[auth_space]]></ChangeType>
   <SpaceId><![CDATA[spxxxxxxxxxxxxx]]></SpaceId>
</xml>
```

说明

参数 | 说明 || ToUserName | 企业微信CorpID |
| FromUserName | 成员UserID |
| CreateTime | 消息创建时间，unix时间戳 |
| MsgType | 消息类型，此时固定为：`event` |
| Event | 事件类型，此时固定为：`wedrive_archive_space_change` |
| ChangeType | 变更类型，目前有授权和取消授权空间两种类型分别为`auth_space`和`cancel_auth_space` |
| SpaceId | 空间spaceid |

### 文件变更事件

当成员在授权范围的空间文件变更会触发该事件，文件变更有如下情况：
1. 创建：包含上传本地格式文件、把本地格式文件存至微盘、继承了文件、将其他文件转入授权空间等
2. 更新文件内容：文件更新、文件重命名等
3. 删除文件：删掉文件、文件继承给别人、文件从授权空间移动到其他空间等

企业收到该事件后，如果是创建或更新文件的变更类型，可以通过[下载文件](#61815)接口获取最新的文件

示例

```javascript
<xml>
   <ToUserName><![CDATA[toUser]]></ToUserName>
   <FromUserName><![CDATA[fromUser]]></FromUserName>
   <CreateTime>1348831860</CreateTime>
   <MsgType><![CDATA[event]]></MsgType>
   <Event><![CDATA[wedrive_archive_file_change]]></Event>
   <ChangeType><![CDATA[create_file]]></ChangeType>
   <FileId><![CDATA[s.xxxxxxxxxxxxx]]></FileId>
   <FileId><![CDATA[s.xxxxxxxxxxxxx]]></FileId>
</xml>
```

说明

参数 | 说明 || ToUserName | 企业微信CorpID |
| FromUserName | 成员UserID |
| CreateTime | 消息创建时间，unix时间戳 |
| MsgType | 消息类型，此时固定为：`event` |
| Event | 事件类型，此时固定为：`wedrive_archive_file_change` |
| ChangeType | 变更类型。有以下值：`create_file`-创建文件 ，`update_file`-更新文件内容，`delete_file` -删除文件 |
| FileId | 文件fileid列表 |
