# 下载文件

可通过此接口下载成员授权范围内的文件，仅支持本地格式文件的下载。

**请求方式：** POST（**HTTPS**）
**请求地址：** https://qyapi.weixin.qq.com/cgi-bin/security/wedrive/download_file?access_token=ACCESS_TOKEN

**请求包体**

```javascript
{
	"fileid":"spxxxxxxxxx"
}
```

**参数说明：**

| 参数 | 是否必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 |
| fileid | 是 | String | 文件ID |

**权限说明：**
调用的应用需要满足如下的权限：

| 应用类型 | 权限要求 |
| --- | --- |
| 自建应用 | 配置到「文件内容存档 - 可调用接口的应用」中 |
| 代开发应用 | 暂不支持 |
| 第三方应用 | 暂不支持 |

**返回结果：**

```json
{
	"errcode": 0,
	"errmsg": "ok",
	"download_url": "DOWNLOAD_URL",
	"cookie_name": "COOKIE_NAME",
	"cookie_value": "COOKIE_VALUE"
}
```

**参数说明：**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| errcode | Integer | 错误码 |
| errmsg | String | 错误码说明 |
| download_url | String | 下载请求url (有效期2个小时) |
| cookie_name | String | 下载请求带cookie的key |
| cookie_value | String | 下载请求带cookie的value |
