# 获取下级企业加入的上下游

上级企业自建应用/代开发应用通过本接口查询下级企业所在上下游

**请求方式：**POST（**HTTPS**）
**请求地址：** https://qyapi.weixin.qq.com/cgi-bin/corpgroup/get_corp_shared_chain_list?access_token=ACCESS_TOKEN

**请求示例**

```json
{
    "corpid":"xxxxx"
}
```

**参数说明 ：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access_token | 是 | 调用接口凭证。上游企业应用access_token |
| corpid | 否 | 已加入企业id |

**权限说明：**

* 自建应用、代开发应用和「[上下游- 可调用接口的应用](./97213.md#%E9%85%8D%E7%BD%AE%E5%8F%AF%E8%B0%83%E7%94%A8%E6%8E%A5%E5%8F%A3%E7%9A%84%E5%BA%94%E7%94%A8)」可调用，仅可指定应用可见范围内的企业

**返回结果：**

```javascript
{
    "errcode": 0,
    "errmsg": "ok",
    "chains": [
      {
         "chain_id": "xxx",
         "chain_name": "xxx"
      }
    ]
}
```

**参数说明：**

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述内容 |
| chains | 上下游列表 |
| chains.chain_id | 上下游id |
| chains.chain_name | 上下游名称 |
