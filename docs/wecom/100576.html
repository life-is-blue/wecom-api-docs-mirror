    • ww.setClipboardData(params)

    兼容性：企业微信 iOS、Android 2.4.16 开始支持，企业微信 PC、Mac 3.1.2 开始支持

    功能描述

    设置系统剪贴板的内容。

    ww.setClipboardData({
  data: 'data'
})

    参数说明

    params: Object

    属性类型必填说明
    datastring是

    剪贴板的内容

    successFunction否

    成功回调

    failFunction否

    失败回调

    cancelFunction否

    取消回调

    completeFunction否

    完成回调

    返回说明

    Promise<Object>

    属性类型必填说明
    errMsgstring是

    通用错误信息

    errCodenumber是

    通用错误码

    旧版jweixin调用

    示例代码

    wx.setClipboardData({
  data: 'data',    // 设置的
  success: function(res) {
      console.log(res.errMsg)
  }
})
