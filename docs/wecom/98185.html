此接口用于停止成员发起的屏幕共享。目前暂不支持 MRA 设备作为被操作者的情况

请求方式： POST（HTTPS）
请求地址： https://qyapi.weixin.qq.com/cgi-bin/meeting/realcontrol/close_screen_share?access_token=ACCESS_TOKEN

 

请求包体：

{
	"meetingid": "meetingid11234",
	"operated_user": {
		"tmp_openid": "MS_OPENID",
		"instance_id": 1
	}
}

参数说明：

参数必须类型说明
access_token是string调用接口凭证。获取方法查看“获取access_token”
meetingid是string会议ID
operated_user是object[]被操作对象，详见User

User说明

参数必须说明 
tmp_openid是string被操作者的会中临时ID
instance_id是int32成员的终端设备类型：
1：PC
2：Mac
3：Android
4：iOS
5：Web
6：iPad
7：Android Pad
9：voip、sip 设备
10：linux
20：Rooms for Touch Windows
21：Rooms for Touch MacOS
22：Rooms for Touch Android
30：Controller for Touch Windows
32：Controller for Touch Android
33：Controller for Touch iOS
81：鸿蒙手机
82：鸿蒙平板
83：鸿蒙PC
84：鸿蒙汽车
说明：请与被操作者的设备类型保持一致，否则不生效。

 

权限说明

  • 仅配置在“可调用接口的应用”列表中的自建应用可调用
  • 仅允许操作该应用创建的会议

 

返回结果：

{
   "errcode": 0,
   "errmsg": "ok"
}

参数说明：

参数类型说明
errcodeint32返回码
errmsgstring对返回码的文本描述内容
