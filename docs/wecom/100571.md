# 监听设备更新

## ww.onBeaconUpdate(callback)

> 兼容性：企业微信

### 功能描述

监听 iBeacon 设备的更新事件。

```ts
ww.onBeaconUpdate(function(event) {
  console.log(event)
})
```

### 参数说明

#### callback: Function

**参数**

**event: Object**
