# 获取成员文档列表

可通过该接口获取『文件内容存档』生效范围内成员拥有的文档列表。
> **注意**
>
> • 查询的用户必须在存档生效范围和应用的可见范围內
> • 仅支持查询企业内成员数大于1的文档
> • 同一企业并发请求数不能超过10

**请求方式**：POST（**HTTPS**）
**请求地址**: https://qyapi.weixin.qq.com/cgi-bin/security/doc/list?access_token=ACCESS_TOKEN

**请求包体**

```json
{
	"start_time": 166666666,
	"end_time": 166666667,
	"userid": "zhangsan",
	"is_resigned":0,
	"doc_type":1,
	"cursor":"ngLgjieajgieo",
	"limit":100
}
```

**参数说明**

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| access_token | string | 是 | 应用调用凭证 |
| start_time | int | 是 | 查询的开始时间，时间戳精确到秒。`根据文档修改时间过滤` |
| end_time | int | 是 | 查询的结束时间，时间戳精确到秒。`根据文档修改时间过滤` |
| userid | string | 是 | 需要查询的用户userid |
| is_resigned | 否 | Interger | 查询已离职或在职的`userid`，默认查询在职。0：在职 1：已离职 |
| doc_type | int | 是 | 查询的文档类型 3: 文档 4: 表格 6: 幻灯片 7: 思维导图 10: 智能表格 |
| cursor | string | 否 | 由企业微信后台返回，第一次调用可不填 |
| limit | int | 否 | 限制返回的条数，最多设置为`100`，不填默认100 |

**调用说明**

* 调用的应用需要满足如下的权限：

| 应用类型 | 权限要求 |
| --- | --- |
| 自建应用 | 配置到「文档内容存档 - 可调用接口的应用」中 |
| 代开发应用 | 暂不支持 |
| 第三方应用 | 暂不支持 |

**返回示例**

```json
{
	"errcode": 0,
	"errmsg": "ok",
	"has_more": true,
	"next_cursor": "gejMjgLjgeigoejg",
	"doc_list":[
	{
		"docid":"docid1111",
		"doc_name":"一季度业绩复盘",
		"userid":"zhangsan",
		"doc_type":1,
		"create_time":1777777777,
		"modify_time":177777778
	}
	]
}
```

**参数说明**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| errcode | int32 | 错误码 |
| errmsg | string | 错误码说明 |
| has_more | bool | 是否还有更多数据 |
| next_cursor | string | 仅has_more值为true时返回该字段，下一次调用将该值填到cursor字段，以实现分页查询 |
| doc_list | array | 文档列表，详见`Document` |

### **Document结构说明**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| docid | string | 文档ID |
| doc_name | string | 文档标题 |
| userid | string | 文档所属员工userid |
| doc_type | int | 文档类型 3-文档 4-表格 6-幻灯片 7-思维导图 10-智能表 |
| create_time | int64 | 文档创建时间 |
| modify_time | int64 | 文档最后修改时间 |
| url | string | 可查看文档内容的地址 |
