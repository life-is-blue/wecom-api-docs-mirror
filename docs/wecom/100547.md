# 获取已连接中的 Wi-Fi 信息

## ww.getConnectedWifi([params])

> 兼容性：企业微信 iOS、Android 2.4.16 开始支持

### 功能描述

获取已连接中的 Wi-Fi 信息。

```ts
ww.getConnectedWifi()
```

### 参数说明

#### params: Object

|  | 属性 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
|  | success | Function | 否 | 成功回调 |
|  | fail | Function | 否 | 失败回调 |
|  | cancel | Function | 否 | 取消回调 |
|  | complete | Function | 否 | 完成回调 |
