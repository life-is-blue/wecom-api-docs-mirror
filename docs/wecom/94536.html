可以添加一级或二级事件类别，网格员在提交「巡查上报」或「居民上报」时将填入配置的事件类别

请求方式： POST（HTTPS）
请求地址： https://qyapi.weixin.qq.com/cgi-bin/report/grid/add_cata?access_token=ACCESS_TOKEN

请求包体：

{
    "category_name": "category_name",
    "level" : 2,
    "parent_category_id": "parent_category_id"
}

参数说明：

参数必须说明
access_token是调用接口凭证。“获取access_token”
category_name是分类名称，不能超过30个字,同一一级分类下的二级分类名字不能一样
level是分类层级，这里只能传1或者2
parent_category_id否所属的一级分类的id，level为2的话必传

权限说明：

应用类型权限要求
自建应用配置到「居民联系 - 可调用接口的应用」中
代开发应用支持，需要勾选「居民联系权限」
第三方应用暂不支持

注： 从2023年12月1日0点起，不再支持通过系统应用secret调用接口，存量企业暂不受影响 查看详情

返回结果：

{
   "errcode": 0,
   "errmsg": "ok",
   "category_id": "category_id"
}

参数说明：

参数说明
errcode返回码
errmsg对返回码的文本描述内容
category_id分类id
