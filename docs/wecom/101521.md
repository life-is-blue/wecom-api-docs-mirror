# 自建应用与智能机器人的对接

将智能机器人获取的密文open\_userid转换为明文userid。
**请求方式：**POST（**HTTPS**）
**请求地址**：https://qyapi.weixin.qq.com/cgi-bin/batch/openuserid\_to\_userid?access\_token=ACCESS\_TOKEN

**请求参数：**

```javascript
{
  "open_userid_list":["xxx", "yyy"]
}
```

**参数说明：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access\_token | 是 | 企业自建应用的调用接口凭证。获取方法查看“[获取access\_token](./15074.md)” |
| open\_userid\_list | 是 | 企业主体下加密的userid列表，最多不超过1000个。 |

**权限说明：**

> 需要使用自建应用的access\_token
> 成员需要在access\_token所对应应用的可见范围内

**返回结果：**

```javascript
{
    "errcode": 0,
    "errmsg": "ok",
    "userid_list": [
        {
            "open_userid": "xxx",
            "userid": "aaa"
        }
    ],
    "invalid_open_userid_list":["yyy"]
}
```

**参数说明：**

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述内容 |
| userid\_list | 明文userid |
| userid\_list.open\_userid | 转换成功的open\_userid |
| userid\_list.userid | 转换成功的open\_userid对应的userid |
| invalid\_open\_userid\_list | 不合法的open\_userid列表。如果传入的已是明文的userid，也会在该列表返回 |
