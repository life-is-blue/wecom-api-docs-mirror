# 获取收款项目的商户单号

获取对外收款项目中每笔收款的商户单号

**请求方式：** POST（**HTTPS**）
**请求地址：** https://qyapi.weixin.qq.com/cgi-bin/externalpay/get\_payment\_info?access\_token=ACCESS\_TOKEN

**请求包体：**

```json
{
   "payment_id":"xxxx"
}
```

**参数说明：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access\_token | 是 | 调用接口凭证 |
| payment\_id | 是 | 收款项目单号。在[发起对外收款](./39955.md)中返回。 |

**权限说明：**
调用的应用需要满足如下的权限，且只允许获取由应用本身创建的收款项目的收款单号列表

| 应用类型 | 权限要求 |
| --- | --- |
| 自建应用 | 配置到「[对外收款- 可调用接口的应用](./93665.md#%E9%85%8D%E7%BD%AE%E5%8F%AF%E8%B0%83%E7%94%A8%E6%8E%A5%E5%8F%A3%E7%9A%84%E5%BA%94%E7%94%A8)」中 |
| 代开发应用 | 具有「对外收款」权限 |
| 第三方应用 | 具有「对外收款」权限 |

*注：* 从2023年12月1日0点起，不再支持通过系统应用secret调用接口，存量企业暂不受影响 [查看详情](https://developer.work.weixin.qq.com/document/51165)

**返回结果：**

```javascript
{
	"errcode": 0,
	"errmsg": "ok",
	"bill_list": [
		{
			"out_trade_no":"xxxx"
		},
		{
			"out_trade_no":"yyyy"
		}
	]
}
```

**参数说明：**

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述内容 |
| out\_trade\_no\_list | 收款单号列表。每笔支付对应一个收款单号 |
