    • ww.openExistedChatWithMsg(params)

    兼容性：企业微信 3.1.8 开始支持

    功能描述

    打开已有群聊并可选发送一条链接消息（link消息）。支持打开企业内部群、外部群、互联群。

    ww.openExistedChatWithMsg({
  chatId: 'chatId123',
  msg: {
    msgtype: 'link',
    link: {
      title: 'title1',
      desc: 'desc1',
      url: 'link1',
      imgUrl: 'imgurl1'
    }
  }
})

    使用限制

    本接口必须使用应用身份进行注册

    参数说明

    params: Object

    属性类型必填说明最低版本
    chatIdstring是

    打开的群聊 ID

    msgObject否

    发送的链接消息。不传则表示仅进入群聊，不发消息

    企业微信 iOS、Android 3.1.8，企业微信 PC、Mac 4.0.2

    属性类型必填说明
    msgtype"link"是

    消息类型

    linkObject是
    属性类型必填说明
    titlestring否

    H5消息标题

    imgUrlstring否

    H5消息封面图片URL

    descstring否

    H5消息摘要

    urlstring是

    H5消息页面url

    successFunction否

    成功回调

    failFunction否

    失败回调

    cancelFunction否

    取消回调

    completeFunction否

    完成回调

    返回说明

    Promise<Object>

    属性类型必填说明
    errMsgstring是

    通用错误信息

    errCodenumber是

    通用错误码

    错误信息

    errMsg说明
    openExistedChatWithMsg:ok执行成功
    openExistedChatWithMsg:fail_unsupported_msgtypemsgtype不合法
    openExistedChatWithMsg:fail_msg_link_missing_urlmsg.link.url未传入

    旧版jweixin调用

    示例代码

                msg: {

                    		url: "link1",
                    		imgUrl: "imgurl1"
                	}
             	}
        },function(res){
                if (res.err_msg == "openExistedChatWithMsg:ok")
                {
                }
        }
