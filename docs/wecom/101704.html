可通过该接口获取『文件内容存档』生效范围内成员拥有的文档列表。
注意
• 查询的用户必须在存档生效范围和应用的可见范围內
• 仅支持查询企业内成员数大于1的文档
• 同一企业并发请求数不能超过10

 

请求方式：POST（HTTPS）
请求地址: https://qyapi.weixin.qq.com/cgi-bin/security/doc/list?access_token=ACCESS_TOKEN

请求包体

{
	"start_time": 166666666,
	"end_time": 166666667,
	"userid": "zhangsan",
	"is_resigned":0,
	"doc_type":1,
	"cursor":"ngLgjieajgieo",
	"limit":100
}

参数说明

参数类型是否必须说明
access_tokenstring是应用调用凭证
start_timeint是查询的开始时间，时间戳精确到秒。根据文档修改时间过滤
end_timeint是查询的结束时间，时间戳精确到秒。根据文档修改时间过滤
useridstring是需要查询的用户userid
is_resigned否Interger查询已离职或在职的userid，默认查询在职。0：在职 1：已离职
doc_typeint是查询的文档类型
3: 文档
4: 表格
6: 幻灯片
7: 思维导图
10: 智能表格
cursorstring否由企业微信后台返回，第一次调用可不填
limitint否限制返回的条数，最多设置为100，不填默认100

调用说明

  • 调用的应用需要满足如下的权限：
应用类型权限要求
自建应用配置到「文档内容存档 - 可调用接口的应用」中
代开发应用暂不支持
第三方应用暂不支持

返回示例

{
	"errcode": 0,
	"errmsg": "ok",
	"has_more": true,
	"next_cursor": "gejMjgLjgeigoejg",
	"doc_list":[
	{
		"docid":"docid1111",
		"doc_name":"一季度业绩复盘",
		"userid":"zhangsan",
		"doc_type":1,
		"create_time":1777777777,
		"modify_time":177777778
	}
	]
}

参数说明

参数类型说明
errcodeint32错误码
errmsgstring错误码说明
has_morebool是否还有更多数据
next_cursorstring仅has_more值为true时返回该字段，下一次调用将该值填到cursor字段，以实现分页查询
doc_listarray文档列表，详见Document

 

Document结构说明

参数类型说明
docidstring文档ID
doc_namestring文档标题
useridstring文档所属员工userid
doc_typeint文档类型
3-文档
4-表格
6-幻灯片
7-思维导图
10-智能表
create_timeint64文档创建时间
modify_timeint64文档最后修改时间
urlstring可查看文档内容的地址
