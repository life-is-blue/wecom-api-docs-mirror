接口说明
小程序应用可以使用该接口提供按钮，让企业管理员打开应用的管理页面，快速进行修改可见范围等操作。

调用前提

必须先调用过wx.qy.login，并且调用时传入suiteId参数

调用人身份要求

企业超级管理员
具有应用管理权限的企业分级管理员

参数

Object object

参数名类型必填说明企业微信版本要求
pageString否指定跳转的应用二级页，不指定时跳转至应用管理首页。可选值见下方 page 参数说明≥4.1.22
suiteIdString否不指定时，表示为跳转agentConfig指定的应用管理页。
指定时，表示为跳转的其他应用管理页。目前仅支持会话内容存档应用。指定的suiteid必须是同服务商的应用，且当前企业有授权关系，同时当前用户必须是超管		≥4.1.22
successFunction否接口调用成功的回调函数
failFunction否接口调用失败的回调函数
completeFunction否接口调用结束的回调函数（调用成功、失败都会执行）

page 参数说明

page 参数值权限名称权限要求
permission应用权限详情页无额外要求
datazone_chat_permission「数据与智能专区」会话数据权限1. 调用身份为超级管理员
2. 应用需要满足勾选了"数据与智能专区权限"（灰度服务商，则为"数据与智能专区权限-分析企业会话内容数据"）
3. 应用类型为第三方应用/代开发应用（注：不支持上下游共享应用）
datazone_doc_permission「数据与智能专区」文档数据权限1. 调用身份为超级管理员
2. 应用需要满足勾选了"数据与智能专区权限-分析企业文档数据"
3. 应用类型为第三方应用（注：不支持上下游共享应用）
datazone_knowledge_permission「数据与智能专区」知识集数据权限1. 调用身份为超级管理员
2. 应用需要满足勾选了"数据与智能专区权限-分析企业知识集数据"
3. 应用类型为第三方应用（注：不支持上下游共享应用）

示例代码：

wx.qy.openAppManage({
    page: "permission", // 非必填，指定跳转的页面地址
    suiteId: "wwabcdefghijk", // 非必填，指定跳转的关联应用
    success: function(res){
            // 调用成功
    },
    fail: function(err){
        // 调用失败
    }
});
