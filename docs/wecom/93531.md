**请求方式：** GET（**HTTPS**）
**请求地址：** https://qyapi.weixin.qq.com/cgi-bin/report/patrol/get\_grid\_info?access\_token=ACCESS\_TOKEN

**参数说明：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access\_token | 是 | 调用接口凭证。“[获取access\_token](https://work.weixin.qq.com/api/doc/90001/90143/90605)” |

**权限说明：**

| 应用类型 | 权限要求 |
| --- | --- |
| 自建应用 | 配置到「[巡查上报 - 可调用接口的应用](#25814/%E9%85%8D%E7%BD%AE%E5%8F%AF%E8%B0%83%E7%94%A8%E6%8E%A5%E5%8F%A3%E7%9A%84%E5%BA%94%E7%94%A8)」中 |
| 代开发应用 | 暂不支持 |
| 第三方应用 | 暂不支持 |

*注：* 从2023年12月1日0点起，不再支持通过系统应用secret调用接口，存量企业暂不受影响 [查看详情](https://developer.work.weixin.qq.com/document/51165)

**返回结果：**

```json
{
   "errcode": 0,
   "errmsg": "ok",
   "grid_list":[
      {
         "grid_id": "grid_id",
         "grid_name": 1,
         "grid_admin": [
            "zhangsan",
            "lisi"
         ]
      }
   ]
}
```

**参数说明：**

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述内容 |
| grid\_list.grid\_id | 网格 ID |
| grid\_list.grid\_name | 网格名称 |
| grid\_list.grid\_admin | 网格管理员 userId 列表 |
