指定会议中导入报名信息。

  • 会议未开启报名时会返回未开启报名错误。

 

请求方式： POST（HTTPS）
请求地址： https://qyapi.weixin.qq.com/cgi-bin/meeting/enroll/import?access_token=ACCESS_TOKEN

请求包体：

{
	"meetingid": "meetingid11234",
	"enroll_list": [{
		"userid": "USERID",
		"area":  "86",
		"phone_number": "13333333333",
		"nick_name": "NICKNAME"
	}]
}

参数说明：

参数必须类型说明
access_token是string调用接口凭证。获取方法查看“获取access_token”
meetingid是string会议ID
enroll_list是object[]报名成员列表。详见EnrollRequest。

EnrollRequest说明

参数必须类型说明
userid否string报名成员 userid
area否string国家/地区代码。若使用 phone_number 的方式导入，该字段必填（例如：中国传86，不是+86）。
phone_number否string手机号。
nick_name否string报名的昵称。此处的修改不会影响会中展示的昵称，仅展示在导出的报名信息。

 

权限说明

  • 仅配置在“可调用接口的应用”列表中的自建应用可调用
  • 仅允许修改该应用创建的会议的数据

 

返回结果：

{
	"errcode": 0,
	"errmsg": "ok",
	"total_count": 1,
	"enroll_list": [{
		"enroll_id": "mexxxxx",
		"userid": "USERID",
		"area": "86",
		"phone_number": "13333333333",
		"nick_name": "NICKNAME",
		"enroll_code": "CODE"
	}]
}

参数说明

参数类型说明
errcodeint32返回码
errmsgstring对返回码的文本描述内容
total_countint32成功导入的报名信息条数
enroll_listobject[]报名成员列表。详见EnrollResponse。

 

EnrollResponse说明

参数类型说明
enroll_idstring报名ID
useridstring报名成员 userid
areastring国家/地区代码。若使用 phone_number 的方式导入，该字段必填（例如：中国传86，不是+86）。
phone_numberstring手机号。
nick_namestring报名的昵称。
enroll_codestring报名码，用于电话入会的凭证。
