# 获取存档成员

可通过此接口获取当前授权应用在企业文件内容存档中的所有生效成员。该成员范围由文档、微盘和日程存档共用，不区分数据品类。
> **注意**

## 请求方式

**请求方式：** POST（**HTTPS**）

**请求地址**

```text
https://qyapi.weixin.qq.com/cgi-bin/security/file-content/get_auth_user_list?access_token=ACCESS_TOKEN
```

## 请求参数

### 请求示例

```json
{
  "cursor": "JMgigeong",
  "limit": 2
}
```

### 参数说明

| 参数 | 是否必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| `access_token` | 是 | String | 调用接口凭证，通过请求 URL 传入 |
| `cursor` | 否 | String | 上一次调用返回的 `next_cursor`。第一次拉取不填，最大长度为 128 字节 |
| `limit` | 否 | Integer | 本次查询返回的最大条数，范围为 1～1000，默认 200 |

## 权限说明

调用应用需要满足以下权限要求：

| 应用类型 | 权限要求 |
| --- | --- |
| 自建应用 | 已配置到“文件内容存档 - 可调用接口的应用”中，并至少开通文档、微盘或日程存档中的一个品类权限 |
| 代开发应用 | 暂不支持 |
| 第三方应用 | 暂不支持 |

## 生效范围说明

接口返回当前应用最终可用于企业文件内容存档的成员集合：

```text
生效成员范围
  = 企业文件内容存档实际生效的总分配成员
  ∩ 当前应用的可见成员范围
  ∩ 当前应用配置的文件内容存档范围
```

## 返回结果

### 返回示例

```json
{
  "errcode": 0,
  "errmsg": "ok",
  "auth_user_list": [
    {
      "userid": "woxxxjigegen",
      "is_resigned": 0
    },
    {
      "userid": "woaaaaaaaaaa",
      "is_resigned": 1
    }
  ],
  "next_cursor": "xjigeojgeigwj",
  "has_more": 1
}
```

### 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `errcode` | Integer | 错误码 |
| `errmsg` | String | 错误码说明 |
| `auth_user_list` | Object 数组 | 实际生效成员列表，成员结构详见 `AuthUser` |
| `next_cursor` | String | 下一次查询使用的游标；`has_more` 为 0 时不返回 |
| `has_more` | Integer | 是否还有更多数据。1：是；0：否 |

### AuthUser

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `userid` | String | 成员的 `userid`，支持返回仍保留在存档范围中的离职或已删除成员 |
| `is_resigned` | Integer | 是否已离职。0：在职；1：已离职或已删除 |

## 分页说明

* 首次调用不传 `cursor`；
* 当返回 `has_more=1` 时，将 `next_cursor` 原样传入下一次请求；
* 成员范围在分页过程中发生变更时，后续页面结果可能随最新生效范围变化。
