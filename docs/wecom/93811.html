    • ww.downloadLivingReplay(params)

    兼容性：企业微信 PC 3.1.0 开始支持

    功能描述

    调起直播回放下载页面。

    ww.downloadLivingReplay({
  livingId: 'LIVINGID'
})

    使用限制

    • 本接口必须使用应用身份进行注册

    • 应用需具有直播使用权限，参考配置可使用直播的应用

    • 只允许直播的发起人下载直播回放

    参数说明

    params: Object

    属性类型必填说明
    livingIdstring是

    直播 ID

    successFunction否

    成功回调

    failFunction否

    失败回调

    cancelFunction否

    取消回调

    completeFunction否

    完成回调

    返回说明

    Promise<Object>

    属性类型必填说明
    errMsgstring是

    通用错误信息

    errCodenumber是

    通用错误码

    错误信息

    errMsg说明
    downloadLivingReplay:ok执行成功
    downloadLivingReplay:fail no permission应用签名校验失败，或应用不具备直播权限
    downloadLivingReplay:fail invalid living id不合法的直播ID
    downloadLivingReplay:fail not allow to cross corp不可跨企业使用直播ID
    downloadLivingReplay:fail not allow to cross app不可跨应用使用直播ID
    downloadLivingReplay:fail invalid parameter参数不合法
    downloadLivingReplay:fail living has no replay不存在直播回放
    downloadLivingReplay:fail replay is beging creating正在直播中，或回放正在生成中，稍后观看回放
    downloadLivingReplay:fail create replay failed回放创建失败
    downloadLivingReplay:fail invalid operator只允许直播的发起人下载直播回放

    旧版jweixin调用

    示例代码

    wx.invoke('downloadLivingReplay', {
		"livingId": "LIVINGID",
	}, function(res) {
		if (res.err_msg != "downloadLivingReplay:ok") {
            // 错误处理
        }
    });
