# 回调通知

企业需要配置下面两项来开启存档的回调通知能力：

1. 设置存档范围
2. 添加可调用接口的应用（应用需要设置接收事件的服务器、可信 IP 地址）

配置后，企业微信会将特定的事件推送给文件内容存档可调用接口的应用配置的`回调URL`。接收并解析事件的方法见：[接收事件](#12977)

## 应用被存档成员变更回调

回调场景：企业调整了被存档成员范围

**示例**

```javascript
<xml>
   <ToUserName><![CDATA[toUser]]></ToUserName>
   <FromUserName><![CDATA[sys]]></FromUserName>
   <CreateTime>1348831860</CreateTime>
   <MsgType><![CDATA[event]]></MsgType>
   <Event><![CDATA[file_content_archive_auth_change]]></Event>
</xml>
```

**说明**

| 参数 | 说明 |
| --- | --- |
| ToUserName | 企业微信CorpID |
| FromUserName | 此事件该值固定为 `sys` ，表示该消息由系统生成 |
| CreateTime | 消息创建时间，unix时间戳 |
| MsgType | 消息类型，此时固定为：`event` |
| Event | 事件类型，此时固定为：`file_content_archive_auth_change` |

## 存档成员范围变化事件

文件内容存档设置的成员存档范围变化会触发该事件，存档范围变化有如下情况：
1. 存档范围减少成员
- 到期未续购
- 符合再分配条件，移除该成员并将微盘内容存档分配给其他人使用
2. 存档范围新增成员的情况
- 企业新设置了生效范围，包括新购、增购、续期后的分配，和调整分配等

企业收到该事件后，可以通过[获取存档成员](#61900)接口获取最新的存档成员列表
**示例**

```javascript
<xml>
   <ToUserName><![CDATA[toUser]]></ToUserName>
   <FromUserName><![CDATA[sys]]></FromUserName>
   <CreateTime>1348831860</CreateTime>
   <MsgType><![CDATA[event]]></MsgType>
   <Event><![CDATA[file_content_archive_user_list_change]]></Event>
</xml>
```

**说明**

| 参数 | 说明 |
| --- | --- |
| ToUserName | 企业微信CorpID |
| FromUserName | 此事件该值固定为`sys`，表示该消息由系统生成 |
| CreateTime | 消息创建时间，unix时间戳 |
| MsgType | 消息类型，此时固定为：`event` |
| Event | 事件类型，此时固定为：`file_content_archive_user_list_change` |
