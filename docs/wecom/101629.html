用于向指定智能文档中添加数据表。

请求方式：POST（HTTPS）

请求地址：https://qyapi.weixin.qq.com/cgi-bin/wedoc/smartdoc/add_smartsheet?access_token=ACCESS_TOKEN

请求包体

{
    "docid": "DOC_ID",
    "info": {
        "title": "数据表标题",
        "after_id": "数据表的block_id"
    }
}

参数说明

参数类型是否必须说明
docidstring是智能文档的文档 id
infoobject是数据表信息
info.titlestring否数据表标题
info.after_idstring否数据表的block_id。不支持非数据表类型的block_id

权限说明

  • 自建应用需配置到"可调用应用"列表中的应用secret所获取的accesstoken来调用（accesstoken如何获取？）
  • 第三方应用需具有"文档"权限
  • 代开发自建应用需具有"文档"权限

返回示例

{
    "errcode": 0,
    "errmsg": "ok",
    "info": {
       "block_id": "BLOCK_ID",
       "title": "数据表标题",
       "sheet_id": "数据表sheet_id",
       "ss_docid": "智能文档docid",
       "after_id": "BLOCK_ID"
    }
}


参数说明

参数类型说明
errcodeint32错误码
errmsgstring错误码说明
infoobject添加成功后返回的数据表信息
info.block_idstringBlock ID（系统生成）
info.titlestring数据表标题
info.sheet_idstring数据表 sheet_id
info.ss_docidstring智能文档 docid
info.after_idstring排序位置（在哪个 Block 之后）
