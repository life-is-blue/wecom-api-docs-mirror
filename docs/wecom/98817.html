删除指定会议的报名信息，支持删除成员手动报名的信息和导入的报名信息。

请求方式： POST（HTTPS）
请求地址： https://qyapi.weixin.qq.com/cgi-bin/meeting/enroll/delete?access_token=ACCESS_TOKEN

请求包体：

{
	"meetingid": "meetingid11234",
	"enroll_id_list": [{
		"enroll_id": "123456"
	}]
}

参数说明：

参数必须类型说明
access_token是string调用接口凭证。获取方法查看“获取access_token”
meetingid是string会议ID
enroll_id_list是object[]报名ID列表。详见EnrollID。

EnrollID说明

参数必须类型说明
enroll_id是string报名ID

 

权限说明

  • 仅配置在“可调用接口的应用”列表中的自建应用可调用
  • 仅允许修改该应用创建的会议的数据

 

返回结果：

{
	"errcode": 0,
	"errmsg": "ok",
	"total_count": 1
}

参数说明

参数类型说明
errcodeint32返回码
errmsgstring对返回码的文本描述内容
total_countint32成功删除的报名信息数量
