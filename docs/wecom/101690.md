# 查询导出结果

企业可通过该接口查询导出任务的状态。

**请求方式**：POST（**HTTPS**）
**请求地址**: https://qyapi.weixin.qq.com/cgi-bin/security/doc/get_export_result?access_token=ACCESS_TOKEN

**请求包体**

```json
{
	"jobid": "docid111111"
}
```

**参数说明**

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| access_token | string | 是 | 应用调用凭证 |
| jobid | string | 是 | 要查询的任务ID |

**调用说明**

* 调用的应用需要满足如下的权限：

| 应用类型 | 权限要求 |
| --- | --- |
| 自建应用 | 配置到「文件内容存档 - 可调用接口的应用」中 |
| 代开发应用 | 暂不支持 |
| 第三方应用 | 暂不支持 |

**返回示例**

```json
{
	"errcode": 0,
	"errmsg": "ok",
	"status":1,
	"download_url":"https://work.weixin.qq.com/download/1234"
}
```

**参数说明**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| errcode | int32 | 错误码 |
| errmsg | string | 错误码说明 |
| status | int | 任务状态 0-导出中 1-完成 2-任务出错 |
| download_url | string | 导出内容的下载链接 `下载链接有效期为30分钟` |
