# 取消高级功能账号

该接口用于撤销分配应用可见范围企业成员的高级功能。

### 取消高级功能账号

**请求方式：** POST（**HTTPS**）
**请求地址：** https://qyapi.weixin.qq.com/cgi-bin/meeting/vip/submit\_batch\_del\_job?access\_token=ACCESS\_TOKEN

**请求包体**

```json
{
  "userid_list": ["zhangsan","lisi","wangwu","zhaoliu"]
}
```

**参数说明：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access\_token | 是 | 调用接口凭证 |
| userid\_list | 是 | 要撤销分配高级功能的企业成员userid列表，单次操作最多限制100个 |

**权限说明：**

| 应用类型 | 权限要求 |
| --- | --- |
| 自建应用 | 配置到「协作 - 会议 - 可调用接口的应用」中 |
| 代开发应用 | 暂不支持 |
| 第三方应用 | 暂不支持 |

**返回结果：**

```javascript
{
   "errcode": 0,
   "errmsg": "ok",
   "jobid": "xxx",
   "invalid_userid_list":["zhaoliu"]
}
```

**参数说明：**

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述内容 |
| jobid | 批量取消高级功能的任务id |
| invalid\_userid\_list | 非法的userid 列表，不在应用可见范围的useri以及无法识别的userid |

### 查询取消高级功能账号结果

**请求方式：** POST（**HTTPS**）
**请求地址：** https://qyapi.weixin.qq.com/cgi-bin/meeting/vip/batch\_del\_job\_result?access\_token=ACCESS\_TOKEN

**请求包体**

```json
{
  "jobid": "xxx"
}
```

**参数说明：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access\_token | 是 | 调用接口凭证 |
| jobid | 是 | 批量取消高级功能的任务id |

**权限说明：**

| 应用类型 | 权限要求 |
| --- | --- |
| 自建应用 | 配置到「协作 - 会议 - 可调用接口的应用」中 |
| 代开发应用 | 暂不支持 |
| 第三方应用 | 暂不支持 |

**返回结果：**

```javascript
{
   "errcode": 0,
   "errmsg": "ok",
   "job_result": {
       "succ_userid_list":["zhangsan","lisi"],
       "fail_userid_list":["wangwu"]
   }
}
```

**参数说明：**

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述内容 |
| job\_result | 执行任务结果详情 |
| succ\_userid\_list | 撤销分配成功的userid列表 |
| fail\_userid\_list | 撤销分配失败的userid列表 |
