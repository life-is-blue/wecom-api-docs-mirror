注意
• 查询的用户必须在存档生效范围和应用的可见范围內
• 仅支持导出企业内成员数大于1的文档
• 同一企业并发请求数不能超过10

请求方式：POST（HTTPS）
请求地址: https://qyapi.weixin.qq.com/cgi-bin/security/doc/export?access_token=ACCESS_TOKEN

请求包体

{
	"docid": "docid111111",
	"export_format":"pdf"
}

参数说明

参数类型是否必须说明
access_tokenstring是应用调用凭证
docidstring是文档ID
export_formatstring是导出文档内容的格式，支持的导出格式详见下表
支持导出的文档类型支持导出的格式
文档docx，pdf
表格xlsx
智能表xlsx
思维导图xmind
幻灯片pptx，pdf

调用说明

  • 调用的应用需要满足如下的权限：
应用类型权限要求
自建应用配置到「文件内容存档 - 可调用接口的应用」中
代开发应用暂不支持
第三方应用暂不支持

返回示例

{
	"errcode": 0,
	"errmsg": "ok",
	"jobid":"jobidxxxxxxx"
}

参数说明

参数类型说明
errcodeint32错误码
errmsgstring错误码说明
jobidstring本次导出任务的ID。任务完成后10分钟失效
