    • ww.shareToExternalMoments(params)

    兼容性：企业微信 iOS、Android 3.1.12 开始支持

    功能描述

    发表内容到客户朋友圈。

    ww.shareToExternalMoments({
  text: {
    content: '企业微信'
  },
  attachments: [
    {
      msgtype: 'image',
      image: {
        imgUrl: 'https://res.mail.qq.com/node/ww/wwmng/style/images/index_share_logo$13c64306.png'
      }
    }
  ]
})

    使用限制

    • 本接口必须使用应用身份进行注册

    • 应用需有客户联系功能权限

    • 当前成员必须配置了客户联系功能

    • 当前成员必须在客户朋友圈使用范围

    • 当前成员必须具备外部沟通管理成员使用权限

    参数说明

    params: Object

    属性类型必填说明
    textObject否

    文本消息

    属性类型必填说明
    contentstring否

    消息文本内容

    使用限制

    最多支持 2000 字

    attachmentsObject[]否

    附件

    使用限制

    最多支持 9 张图片、1 个视频或 1 个链接

    可能为以下类型

    属性类型必填说明
    msgtype"image"是

    消息类型

    imageObject是
    属性类型必填说明
    mediaidstring否

    图片的素材 ID

    可以通过素材管理接口获得，暂不支持公众平台的 mediaid

    imgUrlstring否

    图片的 url，跟图片素材 ID 填其中一个即可

    或

    属性类型必填说明
    msgtype"link"是

    消息类型

    linkObject是
    属性类型必填说明
    titlestring否

    H5消息标题

    imgUrlstring否

    H5消息封面图片URL

    descstring否

    H5消息摘要

    urlstring是

    H5消息页面url

    或

    属性类型必填说明
    msgtype"video"是

    消息类型

    videoObject是
    属性类型必填说明
    mediaidstring是

    视频的素材 ID

    可以通过素材管理接口获得，暂不支持公众平台的 mediaid

    successFunction否

    成功回调

    failFunction否

    失败回调

    cancelFunction否

    取消回调

    completeFunction否

    完成回调

    返回说明

    Promise<Object>

    属性类型必填说明
    errMsgstring是

    通用错误信息

    errCodenumber是

    通用错误码

    旧版jweixin调用

    示例代码

    wx.invoke("shareToExternalMoments", {
      text: {
            content:"",    // 文本内容
      },
      attachments: [
	        {
            	  msgtype: "image",    // 消息类型，必填
				  image: {
						mediaid: "",      // 图片的素材id
						imgUrl: "",        // 图片的imgUrl,跟图片mediaid填其中一个即可
				  },
			},
			{
				  msgtype: "link",    // 消息类型，必填
				  link: {
						title: "",        // H5消息标题
					    imgUrl: "",    // H5消息封面图片URL
					    url: "",        // H5消息页面url 必填
				  },
			},
			{
				  msgtype: "video",    // 消息类型，必填
				  video:{
						mediaid:"",        // 视频的素材id
				 },
			},
      ]},function(res) {
        if (res.err_msg == "shareToExternalMoments:ok") {
        }
	}
);
