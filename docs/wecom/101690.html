企业可通过该接口查询导出任务的状态。

请求方式：POST（HTTPS）
请求地址: https://qyapi.weixin.qq.com/cgi-bin/security/doc/get_export_result?access_token=ACCESS_TOKEN

请求包体

{
	"jobid": "docid111111"
}

参数说明

参数类型是否必须说明
access_tokenstring是应用调用凭证
jobidstring是要查询的任务ID

调用说明

  • 调用的应用需要满足如下的权限：
应用类型权限要求
自建应用配置到「文件内容存档 - 可调用接口的应用」中
代开发应用暂不支持
第三方应用暂不支持

返回示例

{
	"errcode": 0,
	"errmsg": "ok",
	"status":1,
	"download_url":"https://work.weixin.qq.com/download/1234"
}

参数说明

参数类型说明
errcodeint32错误码
errmsgstring错误码说明
statusint任务状态
0-导出中
1-完成
2-任务出错
download_urlstring导出内容的下载链接
下载链接有效期为30分钟
