该接口用于获取智能文档绑定的数据源信息。
支持的数据表接口/回调如下：

接口说明
添加字段在数据表里添加字段
删除字段在数据表里删除字段
更新字段在数据表里更新字段
查询字段查询数据表字段列表
添加记录在数据表里添加记录
删除记录在数据表里删除记录
更新记录在数据表里更新记录
查询记录查询数据表记录列表
字段变更事件数据表的字段变更回调事件
记录变更事件数据表的记录变更回调事件

 

请求方式：POST（HTTPS）
请求地址: https://qyapi.weixin.qq.com/cgi-bin/wedoc/smartdoc/get_smartsheet_info?access_token=ACCESS_TOKEN

请求包体

{
    "docid": "DOC_ID"
}


参数说明

参数类型是否必须说明
docidstring是智能文档的文档 id，可通过 新建文档 接口创建


权限说明

  • 自建应用需配置到"可调用应用"列表中的应用secret所获取的accesstoken来调用（accesstoken如何获取？）
  • 第三方应用需具有"文档"权限
  • 代开发自建应用需具有"文档"权限

 

返回示例

{
    "errcode": 0,
    "errmsg": "ok",
    "ss_docid": "SS_DOC_ID"
}

参数说明

参数类型说明
errcodeint32错误码
errmsgstring错误码说明
ss_docidstring绑定的数据表docid。若之前已绑定则返回已有的docid，否则自动创建后返回新的docid
