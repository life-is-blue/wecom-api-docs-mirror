用于批量更新指定页面中已有的 Block。

请求方式：POST（HTTPS）
请求地址：https://qyapi.weixin.qq.com/cgi-bin/wedoc/smartdoc/update_blocks?access_token=ACCESS_TOKEN

请求包体

{
    "docid": "DOC_ID",
    "page_id": "PAGE_ID",
    "blocks": [
        {
            "id": "BLOCK_ID",
            "type": "BLOCK_TYPE_TEXT",
            "content": "Updated Content",
            "props": {}
        }
    ]
}


请求参数说明

参数类型是否必须说明
docidstring是智能文档的文档 id
page_idstring是页面的id
blocksobject[](BlockInfo)是需要更新的 Block 列表
blocks[].idstring是需要更新的 Block ID
blocks[].typestring否Block 类型，参见 BlockType
blocks[].titlestring否Block 的文本内容
blocks[].parent_idstring否父节点 Block ID
blocks[].after_idstring否插入位置，表示排在哪个 Block 之后，为空表示插入到最前
blocks[].childrenstring[]否子节点 ID 列表
blocks[].propsBlockProps否Block 属性

权限说明

  • 自建应用需配置到"可调用应用"列表中的应用secret所获取的accesstoken来调用
  • 第三方应用需具有"文档"权限
  • 代开发自建应用需具有"文档"权限

返回示例

{
    "errcode": 0,
    "errmsg": "ok",
    "blocks": [
        {
            "id": "BLOCK_ID",
            "type": "BLOCK_TYPE_TEXT",
            "title": "Updated Content",
            "parent_id": "PARENT_BLOCK_ID",
            "children": [],
            "props": {}
        }
    ]
}


返回参数说明

参数类型说明
errcodeint32错误码
errmsgstring错误码说明
blocksobject[](BlockInfo)更新成功后返回的 Block 列表
