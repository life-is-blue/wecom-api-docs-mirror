# 获取文件列表

可通过此接口获取开启微盘内容存档成员所授权的空间内所上传或继承的文件列表，包含文件名、类型、创建者、大小等。

**请求方式：** POST（**HTTPS**）
**请求地址：** https://qyapi.weixin.qq.com/cgi-bin/security/wedrive/get_auth_file_list?access_token=ACCESS_TOKEN

**请求包体**

```javascript
{
    "userid": "woxxxxxxxxx",
    "is_resigned": 0,
    "spaceid": "spxxxxxxxxx",
    "cursor": "JMgigeong",
    "limit": 2
}
```

**参数说明：**

| 参数 | 是否必须 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 |
| userid | 是 | String | 成员userid |
| is_resigned | 否 | Interger | 查询已离职或在职的`userid`，默认查询在职。0：在职 1：已离职 |
| spaceid | 是 | String | 空间ID |
| cursor | 否 | String | 上一次调用时返回的next_cursor，第一次拉取可以不填 |
| limit | 否 | Interger | 本次查询返回的最大条数。不超过100，默认100条 |

**权限说明：**
调用的应用需要满足如下的权限：

| 应用类型 | 权限要求 |
| --- | --- |
| 自建应用 | 配置到「文件内容存档 - 可调用接口的应用」中 |
| 代开发应用 | 暂不支持 |
| 第三方应用 | 暂不支持 |

**返回结果：**

```json
{
    "errcode": 0,
    "errmsg": "ok",
    "file_list": [
        {
            "fileid": "spxxxx",
            "file_name": "文件名",
			"path":"文件夹/文件名",
            "creator": {
                "userid": "文件创建userid"
            },
            "file_size": 1024,
            "file_type": 1,
            "doc_url": "在线文档url"
        }
    ],
    "next_cursor": "xjigeojgeigwj",
    "has_more": true
}
```

**参数说明：**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| errcode | Integer | 错误码 |
| errmsg | String | 错误码说明 |
| file_list | Object数据 | 文件列表信息，详见**FileInfo** |
| next_cursor | String | 下一次查询时使用，将值填到请求包的cursor字段中 |
| has_more | Integer | 是否还有更多未拉取的数据，1：是；0：否 |

**FileInfo**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| fileid | String | 文件ID |
| file_name | String | 文件名 |
| path | String | 文件的绝对路径（不包括空间节点）。当满足以下两个条件时，该字段会返回： 1. 文件所在的空间超管在存档人员范围内  2. 空间在超管的授权存档范围内 |
| creator | Object | 文件创建者信息 |
| creator.userid | String | 文件创建者userid |
| file_size | Interger | 文件大小 |
| file_type | Interger | 文件类型。1：在线文档 2：普通文件 |
| doc_url | String | 在线文档url。当`file_type`为`1`时返回 |
