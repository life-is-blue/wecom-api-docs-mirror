    • ww.getLocalImgData(params)

    兼容性：企业微信 iOS 2.4.6 开始支持

    功能描述

    获取本地图片内容。

    ww.getLocalImgData({
  localId: localId
})

    使用限制

    仅在 iOS WKWebView 下支持。

    参数说明

    params: Object

    属性类型必填说明
    localIdstring是

    图片的local ID

    successFunction否

    成功回调

    failFunction否

    失败回调

    cancelFunction否

    取消回调

    completeFunction否

    完成回调

    返回说明

    Promise<Object>

    属性类型必填说明
    errMsgstring是

    通用错误信息

    errCodenumber是

    通用错误码

    localDatastring是

    图片的 base64 数据

    旧版jweixin调用

    示例代码

    wx.getLocalImgData({
    localId: '', // 图片的localID
    success: function (res) {
        var localData = res.localData; // localData是图片的base64数据，可以用img标签显示
}
});
