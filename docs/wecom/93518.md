# 获取居民上报事件列表

**请求方式：** POST（**HTTPS**）
**请求地址：** https://qyapi.weixin.qq.com/cgi-bin/report/resident/get\_order\_list?access\_token=ACCESS\_TOKEN

**请求包体：**

```json
{
   "begin_create_time": 12345678,
   "begin_modify_time": 12345678,
   "cursor": "cursor",
   "limit": 20,
}
```

**参数说明：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access\_token | 是 | 调用接口凭证。获取方法查看“[获取access\_token](https://work.weixin.qq.com/api/doc/90001/90143/90605)” |
| begin\_create\_time | 否 | 时间戳，筛选返回begin\_create\_time之后新创建的上报 |
| begin\_modify\_time | 否 | 时间戳，筛选返回begin\_modify\_time之后新修改的上报 |
| cursor | 否 | 翻页参数，首次查询为空，如果查询条件有变更，需要将这个字段置空 |
| limit | 否 | 单页单数，如果不填，默认20条，最大50 |

**权限说明：**

| 应用类型 | 权限要求 |
| --- | --- |
| 自建应用 | 配置到「[居民上报 - 可调用接口的应用](./93513.md#%E9%85%8D%E7%BD%AE%E5%8F%AF%E8%B0%83%E7%94%A8%E6%8E%A5%E5%8F%A3%E7%9A%84%E5%BA%94%E7%94%A8)」中 |
| 代开发应用 | 暂不支持 |
| 第三方应用 | 暂不支持 |

*注：* 从2023年12月1日0点起，不再支持通过系统应用secret调用接口，存量企业暂不受影响 [查看详情](https://developer.work.weixin.qq.com/document/51165)

**参数说明：**

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述内容 |
| next\_cursor | 获取下一页数据的凭据，为空字符串代表是最后一页 |
| order\_list.order\_id | 工单id |
| order\_list.desc | 事件描述 |
| order\_list.urge\_type | 紧急程度，1:一般，2:重要，3:紧急 |
| order\_list.case\_name | 事件类别名称 |
| order\_list.grid\_name | 所属网格名称 |
| order\_list.grid\_id | 所属网格id |
| order\_list.create\_time | 创建时间 |
| order\_list.reporter\_name | 上报人名称 |
| order\_list.reporter\_mobile | 上报人手机 |
| order\_list.unionid | 上报人unionid，企业绑定了微信开发者ID有此字段。[查看绑定方法](./92114.md#%E5%A6%82%E4%BD%95%E7%BB%91%E5%AE%9A%E5%BE%AE%E4%BF%A1%E5%BC%80%E5%8F%91%E8%80%85ID) |
| order\_list.image\_urls | 工单图片列表 |
| order\_list.video\_media\_ids | 工单视频列表 |
| order\_list.location | 发生地点 |
| order\_list.location.name | 位置名 |
| order\_list.location.address | 地址详情说明 |
| order\_list.location.latitude | 纬度，浮点数，范围为90 ~ -90 |
| order\_list.location.longitude | 经度，浮点数，范围为180 ~ -180 |
| order\_list.processor\_userids | 当前流程处理人列表 |
| order\_list.process\_list | 历史流程列表 |
| order\_list.process\_list.process\_type | 流程类型, 2:受理 3:分配 4:转交 5:办结 6:拒绝 7:办理中 |
| order\_list.process\_list.solve\_userid | 该流程的办结人 |
| order\_list.process\_list.process\_desc | 处理流程详细描述 |
| order\_list.process\_list.status | 当前流程状态, 0:处理中，1:已处理 |
| order\_list.process\_list.solved\_time | 处理时间 |
| order\_list.process\_list.image\_urls | 流程图片列表 |
| order\_list.process\_list.video\_media\_ids | 流程视频列表 |
