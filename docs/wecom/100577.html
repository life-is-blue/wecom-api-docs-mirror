    • ww.openLocation(params)

    功能描述

    使用企业微信内置地图查看位置。

    ww.openLocation({
  latitude: 0,
  longitude: 0,
  name: 'name',
  address: 'address',
  scale: 1
})

    参数说明

    params: Object

    属性类型默认值必填说明
    latitudenumber是

    纬度

    范围为 90 ~ -90

    longitudenumber是

    经度

    范围为 180 ~ -180

    namestring否

    位置名

    addressstring否

    地址详情说明

    scalenumber

    16

    		否

    地图缩放级别

    范围为 1 ~ 28

    infoUrlstring否
    successFunction否

    成功回调

    failFunction否

    失败回调

    cancelFunction否

    取消回调

    completeFunction否

    完成回调

    返回说明

    Promise<Object>

    属性类型必填说明
    errMsgstring是

    通用错误信息

    errCodenumber是

    通用错误码

    旧版jweixin调用

    示例代码

    wx.openLocation({
    latitude: 0, // 纬度，浮点数，范围为90 ~ -90
    longitude: 0, // 经度，浮点数，范围为180 ~ -180。
    name: '', // 位置名
    address: '', // 地址详情说明
    scale: 1, // 地图缩放级别,整形值,范围从1~28。默认为16
});
