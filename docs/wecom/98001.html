该接口用于删除已有的公共邮箱。

请求方式：POST（HTTPS）
请求地址: https://qyapi.weixin.qq.com/cgi-bin/exmail/publicmail/delete?access_token=ACCESS_TOKEN

请求包体

{
  "id": 1
}

参数说明

参数类型是否必须说明
iduint32是公共邮箱ID

权限说明

  • 自建应用需配置到“可调用应用”列表中的应用secret所获取的accesstoken来调用（accesstoken如何获取？）
  • 应用调用接口只能访问自身创建的公共邮箱

 

返回示例

{
   "errcode": 0,
   "errmsg": "ok"
}

参数说明

参数类型说明
errcodeint32错误码
errmsgstring错误码说明
