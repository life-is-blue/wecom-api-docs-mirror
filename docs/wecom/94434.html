    • ww.claimClassAdmin([params])

    兼容性：企业微信 3.1.8 开始支持

    功能描述

    跳转到认领班级的界面。

    ww.claimClassAdmin()

    使用限制

    本接口必须使用应用身份进行注册

    参数说明

    params: Object

    属性类型必填说明
    successFunction否

    成功回调

    failFunction否

    失败回调

    cancelFunction否

    取消回调

    completeFunction否

    完成回调

    返回说明

    Promise<Object>

    属性类型必填说明
    errMsgstring是

    通用错误信息

    errCodenumber是

    通用错误码

    departmentIdsstring[]是

    认领的班级部门 ID 列表

    错误信息

    errMsg说明
    claimClassAdmin:ok执行成功
    claimClassAdmin:fail no permission应用身份鉴权失败
    claimClassAdmin:fail user not in allow list当前成员不在应用可见范围
