接口说明：调用该接口，可选择一个或多个自己创建的文档，选中后返回对应文档的docid与url，应用可在数据与智能专区中使用这些文档调用通用模型能力进行分析（灰度内测中）。
企业微信版本 ≥5.0.9 支持选择更多品类，包括文档、表格、智能表格、智能文档、幻灯片、思维导图、流程图、收集表。

调用前提：

必须先调用过wx.qy.login，且session_key未过期，开发者可调用checkSession 检查当前登录态。
当前成员必须在应用的可见范围之中，否则调用时会报“no permission”错误。
应用需具有数据与智能专区文档存档权限，且成员在该应用的文档存档范围内，否则调用时会报“no permission”错误。

wx.qy.selectDatazoneDoc(Object object)

参数

Object object
参数名类型必填说明
success否Function接口调用成功的回调函数
fail否Function接口调用失败的回调函数
complete否Function接口调用结束的回调函数（调用成功、失败都会执行）

返回结果

Object res
参数名类型说明
resObj返回信息
res.errMsgstring执行结果。"selectDatazoneDoc:ok" 表示执行成功，否则表示报错信息
res.docListArray<object>返回的文档列表
res.docList[].docidstring选择的文档docid
res.docList[].urlstring选择的文档url
res.docList[].typenumber选择的文档类型，企业微信版本 ≥5.0.9 支持。0: 其他，3: 文档，4: 表格，5: 收集表，6: 幻灯片，7: 思维导图，8: 流程图，10: 智能表格，11: 智能文档

示例代码

wx.qy.selectDatazoneDoc({
	success: function(res) {
		var docList = res.docList;
		for (var i = 0; i < docList.length; i++)
     	{
				var docid = docList[i].docid;
				var url = docList[i].url;
				var type = docList[i].type;
     	}
	},
	fail: function(res) {
		console.log(res)
	},
});

错误列表说明

res.errMsg说明
selectDatazoneDoc:ok执行成功
selectDatazoneDoc:cancel取消选择
selectDatazoneDoc:fail no session or expired没有调用 wx.qy.login，或者 session_key 已过期
selectDatazoneDoc:fail no permission无权限
selectDatazoneDoc:fail param error参数错误
selectDatazoneDoc:fail context error选择器异常
selectDatazoneDoc:fail not supported system version低系统版本不支持
