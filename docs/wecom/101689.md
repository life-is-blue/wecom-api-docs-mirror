# 创建导出任务

> **注意**
>
> • 查询的用户必须在存档生效范围和应用的可见范围內
> • 仅支持导出企业内成员数大于1的文档
> • 同一企业并发请求数不能超过10

**请求方式**：POST（**HTTPS**）
**请求地址**: https://qyapi.weixin.qq.com/cgi-bin/security/doc/export?access_token=ACCESS_TOKEN

**请求包体**

```json
{
	"docid": "docid111111",
	"export_format":"pdf"
}
```

**参数说明**

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| access_token | string | 是 | 应用调用凭证 |
| docid | string | 是 | 文档ID |
| export_format | string | 是 | 导出文档内容的格式，支持的导出格式详见下表 |

| 支持导出的文档类型 | 支持导出的格式 |
| --- | --- |
| 文档 | docx，pdf |
| 表格 | xlsx |
| 智能表 | xlsx |
| 思维导图 | xmind |
| 幻灯片 | pptx，pdf |

**调用说明**

* 调用的应用需要满足如下的权限：

| 应用类型 | 权限要求 |
| --- | --- |
| 自建应用 | 配置到「文件内容存档 - 可调用接口的应用」中 |
| 代开发应用 | 暂不支持 |
| 第三方应用 | 暂不支持 |

**返回示例**

```json
{
	"errcode": 0,
	"errmsg": "ok",
	"jobid":"jobidxxxxxxx"
}
```

**参数说明**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| errcode | int32 | 错误码 |
| errmsg | string | 错误码说明 |
| jobid | string | 本次导出任务的ID。`任务完成后10分钟失效` |
