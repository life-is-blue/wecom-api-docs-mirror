用于获取指定智能文档中的页面层级结构信息。

请求方式：POST（HTTPS）
请求地址：https://qyapi.weixin.qq.com/cgi-bin/wedoc/smartdoc/get_page_hierarchy?access_token=ACCESS_TOKEN

请求包体

{
    "docid": "DOC_ID"
}

参数说明

参数类型是否必须说明
docidstring是智能文档的文档 id，可通过 新建文档 接口创建


权限说明

  • 自建应用需配置到"可调用应用"列表中的应用secret所获取的accesstoken来调用
  • 第三方应用需具有"文档"权限
  • 代开发自建应用需具有"文档"权限

返回示例

{
    "errcode": 0,
    "errmsg": "ok",
    "pages": [
        {
            "page_id": "PAGE_ID_1",
            "parent_id": "",
            "title": "首页"
        },
        {
            "page_id": "PAGE_ID_2",
            "parent_id": "PAGE_ID_1",
            "title": "子页面1"
        },
        {
            "page_id": "PAGE_ID_3",
            "parent_id": "PAGE_ID_1",
            "title": "子页面2"
        }
    ]
}


参数说明

参数类型说明
errcodeint32错误码
errmsgstring错误码说明
pagesobject[]页面层级列表
pages[].page_idstring页面 ID
pages[].parent_idstring父页面 ID，为空表示是根页面
pages[].titlestring页面标题

页面层级关系说明

通过 parent_id 字段可以构建页面的树形层级结构

首页 (parent_id = "")
├── 子页面1 (parent_id = "首页的page_id")
│   ├── 孙页面1 (parent_id = "子页面1的page_id")
│   └── 孙页面2 (parent_id = "子页面1的page_id")
└── 子页面2 (parent_id = "首页的page_id")
