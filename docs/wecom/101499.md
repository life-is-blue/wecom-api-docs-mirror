# 数据与智能专区文档选择

## ww.selectDatazoneDoc([params])

> 兼容性：企业微信 5.0.8 开始支持

### 功能描述

选择一个或多个自己创建的doc文档，选中后返回对应文档的docid与url。
应用可在数据与智能专区中使用这些文档调用通用模型能力进行分析（灰度内测中）。

```ts
ww.selectDatazoneDoc()
```

### 使用限制

* 本接口必须先使用 ww.register 进行应用身份注册
* 当前成员必须在应用的可见范围内，且在该应用的文件内容存档范围内，否则调用时会报"no permission"错误
* 应用需具有「数据与智能专区文档存档权限」（灰度内测中）

### 参数说明

#### params: Object

| 属性 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| success | Function | 否 | 成功回调 |
| fail | Function | 否 | 失败回调 |
| cancel | Function | 否 | 取消回调 |
| complete | Function | 否 | 完成回调 |

### 返回说明

**Promise<Object>**

| 属性 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| errMsg | string | 是 | 通用错误信息 |
| errCode | number | 是 | 通用错误码 |
| docList | Object[] | 是 | 返回的文档列表 |

docList 子字段：

| 属性 | 类型 | 必填 | 说明 | 最低版本 |
| --- | --- | --- | --- | --- |
| docid | string | 是 | 选择的文档docid |  |
| url | string | 是 | 选择的文档url |  |
| type | number | 是 | 选择的文档类型 | 企业微信 5.0.9 |

type 合法值：

| 合法值 | 说明 |
| --- | --- |
| 0 | 其他 |
| 3 | 文档 |
| 4 | 表格 |
| 5 | 收集表 |
| 6 | 幻灯片 |
| 7 | 思维导图 |
| 8 | 流程图 |
| 10 | 智能表格 |
| 11 | 智能文档 |

## 旧版jweixin调用

```javascript
wx.invoke('selectDatazoneDoc', {
}, function (res) {
  if (res.err_msg == "selectDatazoneDoc:ok") {
        var docList = res.docList;
        for (var i = 0; i < docList.length; i++)
        {
                var docid = docList[i].docid;
                var url = docList[i].url;
        }
  }
});
```
