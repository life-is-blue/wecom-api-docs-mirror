# 批量隐藏功能按钮

## ww.hideMenuItems(params)

### 功能描述

批量隐藏功能按钮。

```ts
ww.hideMenuItems({
  menuList: ['menuItem:setFont']
})
```

### 参数说明

#### params: Object

|  | 属性 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
|  | menuList | string[] | 是 | 要隐藏的菜单项 |
|  | success | Function | 否 | 成功回调 |
|  | fail | Function | 否 | 失败回调 |
|  | cancel | Function | 否 | 取消回调 |
|  | complete | Function | 否 | 完成回调 |

### 返回说明

**Promise<Object>**

|  | 属性 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
|  | errMsg | string | 是 | 通用错误信息 |
|  | errCode | number | 是 | 通用错误码 |

### 使用说明

完整功能按钮列表请参考[所有菜单项列表](#14926)。

## 旧版jweixin调用

### 示例代码

```javascript
wx.hideMenuItems({
    menuList: [] // 要隐藏的菜单项
});
```
