ww.selectDatazoneDoc([params])

兼容性：企业微信 5.0.8 开始支持

功能描述

选择一个或多个自己创建的doc文档，选中后返回对应文档的docid与url。
应用可在数据与智能专区中使用这些文档调用通用模型能力进行分析（灰度内测中）。

ww.selectDatazoneDoc()

使用限制

  • 本接口必须先使用 ww.register 进行应用身份注册
  • 当前成员必须在应用的可见范围内，且在该应用的文件内容存档范围内，否则调用时会报"no permission"错误
  • 应用需具有「数据与智能专区文档存档权限」（灰度内测中）

参数说明

params: Object

属性类型必填说明
successFunction否成功回调
failFunction否失败回调
cancelFunction否取消回调
completeFunction否完成回调

返回说明

Promise<Object>

属性类型必填说明
errMsgstring是通用错误信息
errCodenumber是通用错误码
docListObject[]是返回的文档列表

docList 子字段：

属性类型必填说明最低版本
docidstring是选择的文档docid
urlstring是选择的文档url
typenumber是选择的文档类型企业微信 5.0.9

type 合法值：

合法值说明
0其他
3文档
4表格
5收集表
6幻灯片
7思维导图
8流程图
10智能表格
11智能文档
