# 批量查询电子发票

**接口说明**：报销方在获得用户选择的电子发票标识参数后，可以通过该接口批量查询电子发票的结构化信息。

**请求方式：**POST（**HTTPS**）
**请求地址**：https://qyapi.weixin.qq.com/cgi-bin/card/invoice/reimburse/getinvoiceinfobatch?access\_token=ACCESS\_TOKEN

**请求包体：**

```javascript
{
	"item_list": [
		{
	  	 "card_id":"CARDID1" ,
	  	 "encrypt_code":"ENCRYPTCODE1"
		},
		{
	 	  "card_id":"CARDID2" ,
	 	  "encrypt_code":"ENCRYPTCODE2"
		}
	]
}
```

**参数说明：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access\_token | 是 | 调用接口凭证 |
| item\_list | 是 | 发票列表 |
| card\_id | 是 | 发票id |
| encrypt\_code | 是 | 加密code |

**权限说明：**

仅认证的企业微信账号并且企业激活人数超过200的企业才有接口权限。

**返回数据：**

```javascript
{
    "errcode": 0,
    "errmsg": "ok",
    "item_list": [
        {
            "card_id": "CARDID",
            "openid": "ofdsfasfsafsafasf",
            "type": "增值税电子普通发票",
            "payee": "深圳市XX有限公司",
            "detail": "可在公司企业微信内报销使用",
            "user_info": {
                "fee": 4000,
                "title": "XX有限公司",
                "billing_time": 1478620800,

				"order_id": "12345678",
                "check_code": "CHECKCODE",

            }
        }
    ]
}
```

**参数说明：**

| 参数 | 说明 | 是否必返回 |
| --- | --- | --- |
| card\_id | 发票id | 是 |
| begin\_time | 发票的有效期起始时间 | 是 |
| end\_time | 发票的有效期截止时间 | 是 |
| openid | 用户标识 | 是 |
| type | 发票类型，如广东增值税普通发票 | 是 |
| payee | 发票的收款方 | 是 |
| detail | 发票详情 | 是 |
| user\_info | 发票的用户信息，见user\_info结构说明 | 是 |

user\_info包含以下信息：

| 参数 | 说明 | 是否必返回 |
| --- | --- | --- |
| fee | 发票加税合计金额，以分为单位 | 是 |
| title | 发票的抬头 | 是 |
| billing\_time | 开票时间，为十位时间戳 | 是 |
| billing\_no | 发票代码 | 是 |
| billing\_code | 发票号码 | 是 |
| tax | 税额,以分为单位 | 是 |
| fee\_without\_tax | 不含税金额，以分为单位 | 是 |
| detail | 发票详情，一般描述的是发票的使用说明 | 是 |
| pdf\_url | 这张发票对应的PDF\_URL | 是 |
| trip\_pdf\_url | 其它消费凭证附件对应的URL，如行程单、水单等 | 否 |
| check\_code | 校验码 | 是 |
| buyer\_number | 购买方纳税人识别号 | 否 |
| buyer\_address\_and\_phone | 购买方地址、电话 | 否 |
| buyer\_bank\_account | 购买方开户行及账号 | 否 |
| seller\_number | 销售方纳税人识别号 | 否 |
| seller\_address\_and\_phone | 销售方地址、电话 | 否 |
| seller\_bank\_account | 销售方开户行及账号 | 否 |
| remarks | 备注 | 否 |
| cashier | 收款人，发票左下角处 | 否 |
| maker | 开票人，发票右下角处 | 否 |
| reimburse\_status | 发报销状态INVOICE\_REIMBURSE\_INIT：发票初始状态，未锁定；INVOICE\_REIMBURSE\_LOCK：发票已锁定；INVOICE\_REIMBURSE\_CLOSURE：发票已核销 | 是 |
| info | 商品信息结构，见下方说明 | 否 |

info包含以下信息：

| 参数 | 说明 | 是否必返回 |
| --- | --- | --- |
| name | 项目（商品）名称 | 是 |
| num | 项目数量 | 否 |
| unit | 项目单位 | 否 |
| price | 单价，以分为单位 | 是 |
