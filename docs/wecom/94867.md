# 撤回应用消息

**请求方式：**POST（**HTTPS**）
**请求地址：**https://qyapi.weixin.qq.com/cgi-bin/message/recall?access\_token=ACCESS\_TOKEN
本接口可以撤回24小时内通过[发送应用消息](./10167.md)接口推送的消息，仅可撤回企业微信端的数据，微信插件端的数据不支持撤回。
**请求包体：**

```javascript
{
	"msgid": "vcT8gGc-7dFb4bxT35ONjBDz901sLlXPZw1DAMC_Gc26qRpK-AK5sTJkkb0128t"
}
```

**参数说明：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access\_token | 是 | 调用接口凭证。获取方法查看“[获取access\_token](#10013/%E7%AC%AC%E4%B8%89%E6%AD%A5%EF%BC%9A%E8%8E%B7%E5%8F%96access_token)” |
| msgid | 是 | 消息ID。从应用发送消息接口处获得。 |

**返回结果：**

```javascript
{
   "errcode": 0,
   "errmsg": "ok"
}
```

**参数说明：**

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述内容 |
