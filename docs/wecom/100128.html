启用了 “截屏/录屏管理”的企业可以通过本接口查询截屏操作记录。

请求方式：POST（HTTPS）
请求地址: https://qyapi.weixin.qq.com/cgi-bin/security/get_screen_oper_record?access_token=ACCESS_TOKEN

请求包体

{
	"start_time": 166666666,
	"end_time": 166666667,
	"userid_list": ["zhangsan", "lisi"],
	"department_id_list" : [2, 3],
	"screen_shot_type": 1,
	"cursor":"ngLgjieajgieo",
	"limit":100
}

参数说明

参数类型是否必须说明
access_tokenstring是应用调用凭证
start_timeint是开始时间
end_timeint是结束时间，开始时间到结束时间的范围不能超过14天
userid_listarray否需要查询的截屏操作者的userid，单次最多可以传100个用户。设置的userid需要在应用的可见范围内
department_id_listarray否需要查询的截屏操作者部门的department_id，单次最多可以传100个部门id。设置的department_id需要在应用的可见范围内
screen_shot_typeint否截屏内容的类型，不设置默认为全部
1: 聊天
2: 通讯录
3: 邮件
4: 文件
5: 日程
6: 其他
cursorstring否由企业微信后台返回，第一次调用可不填
limitint否限制返回的条数，最多设置为1000

 

调用说明

  • 调用的应用需要满足如下的权限：
应用类型权限要求
自建应用配置到「截屏/录屏管理 - 可调用接口的应用」中
代开发应用暂不支持
第三方应用暂不支持
  • 返回结果中应用可见范围外用户相关的数据会被过滤掉，不会返回

参数说明

参数类型说明
errcodeint32错误码
errmsgstring错误码说明
has_morebool是否还有更多数据
next_cursorstring仅has_more值为true时返回该字段，下一次调用将该值填到cursor字段，以实现分页查询
record_list.timeint操作时间
record_list.useridstring企业用户账号id
record_list.department_idint企业用户部门id。仅当department_id在应用可见范围内才返回
record_list.screen_shot_typeint截屏内容的类型
1: 聊天
2: 通讯录
3: 邮件
4: 文件
5: 日程
6: 其他
record_list.screen_shot_contentstring截屏内容
record_list.systemstring企业用户的操作系统，目前支持返回的类型：iOS、iPad
record_list.operation_typeint操作类型
0：截屏
1：录屏
record_list.device_infoobject设备信息，详见DeviceInfo
record_list.ipstring设备IP和地址
