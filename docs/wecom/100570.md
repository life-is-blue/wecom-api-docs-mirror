# 获取已搜索到的设备

## ww.getBeacons([params])

> 兼容性：企业微信

### 功能描述

获取所有已搜索到的 iBeacon 设备。

```ts
ww.getBeacons()
```

### 参数说明

#### params: Object

|  | 属性 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
|  | success | Function | 否 | 成功回调 |
|  | fail | Function | 否 | 失败回调 |
|  | cancel | Function | 否 | 取消回调 |
|  | complete | Function | 否 | 完成回调 |
