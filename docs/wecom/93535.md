**请求方式：** POST（**HTTPS**）
**请求地址：** https://qyapi.weixin.qq.com/cgi-bin/report/patrol/get\_order\_info?access\_token=ACCESS\_TOKEN

**请求包体：**

```json
{
   "order_id": "order_id"
}
```

**参数说明：**

| 参数 | 必须 | 说明 |
| --- | --- | --- |
| access\_token | 是 | 调用接口凭证。获取方法查看“[获取access\_token](https://work.weixin.qq.com/api/doc/90001/90143/90605)” |
| order\_id | 是 | 工单id，支持通过工单id直接查询某工单，此参数不为空的话，其他参数无效 |

**权限说明：**

| 应用类型 | 权限要求 |
| --- | --- |
| 自建应用 | 配置到「[巡查上报 - 可调用接口的应用](#25814/%E9%85%8D%E7%BD%AE%E5%8F%AF%E8%B0%83%E7%94%A8%E6%8E%A5%E5%8F%A3%E7%9A%84%E5%BA%94%E7%94%A8)」中 |
| 代开发应用 | 暂不支持 |
| 第三方应用 | 暂不支持 |

*注：* 从2023年12月1日0点起，不再支持通过系统应用secret调用接口，存量企业暂不受影响 [查看详情](https://developer.work.weixin.qq.com/document/51165)

**参数说明：**

| 参数 | 说明 |
| --- | --- |
| errcode | 返回码 |
| errmsg | 对返回码的文本描述内容 |
| order\_info.order\_id | 工单id |
| order\_info.desc | 事件描述 |
| order\_info.urge\_type | 紧急程度，1:一般，2:重要，3:紧急 |
| order\_info.case\_name | 事件类别名称 |
| order\_info.grid\_name | 所属网格名称 |
| order\_info.grid\_id | 所属网格id |
| order\_info.create\_time | 创建时间 |
| order\_info.image\_urls | 工单图片列表 |
| order\_info.video\_media\_ids | 工单视频列表 |
| order\_info.location | 发生地点 |
| order\_info.location.name | 位置名 |
| order\_info.location.address | 地址详情说明 |
| order\_info.location.latitude | 纬度，浮点数，范围为90 ~ -90 |
| order\_info.location.longitude | 经度，浮点数，范围为180 ~ -180 |
| order\_info.processor\_userids | 当前流程处理人列表 |
| order\_info.process\_list | 历史流程列表 |
| order\_info.process\_list.process\_type | 流程类型,1:创建 2:受理 3:分配 4:转交 5:办结 6:拒绝 7:办理中 |
| order\_info.process\_list.solve\_userid | 该流程的办结人 |
| order\_info.process\_list.process\_desc | 处理流程详细描述 |
| order\_info.process\_list.status | 当前流程状态, 0:处理中，1:已处理 |
| order\_info.process\_list.solved\_time | 处理时间 |
| order\_info.process\_list.image\_urls | 流程图片列表 |
| order\_info.process\_list.video\_media\_ids | 流程视频列表 |
