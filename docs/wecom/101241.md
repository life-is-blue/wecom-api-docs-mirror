## 更新记录

可通过智能表格工作表的 Webhook地址 更新一行或多行记录。
**注意**
暂不支持通过Webhook给公式、自动编号、查找引用、创建人、创建时间、最后编辑人、最后编辑时间、群聊、文件字段更新记录。

**请求方式**：POST(HTTPS)
**请求地址**：https://qyapi.weixin.qq.com/cgi-bin/wedoc/smartsheet/webhook?key=KEY

> 开启「接收外部数据」获取到的工作表Webhook地址即为请求地址，启用入口详见[配置说明](#60593/%E6%95%B0%E6%8D%AE%E5%86%99%E5%85%A5%E9%85%8D%E7%BD%AE%E8%AF%B4%E6%98%8E)
> 请求包体写法请参考对应工作表提供的「示例数据」，示例数据位置详见[配置说明](#60593/%E6%95%B0%E6%8D%AE%E5%86%99%E5%85%A5%E9%85%8D%E7%BD%AE%E8%AF%B4%E6%98%8E)

**请求包体**：

```json
{
    "update_records": [
        {
            "record_id": "RECORD_ID",
            "values": {
                "FIELD_ID": [
                    {
                        "type": "text",
                        "text": "文本内容"
                    }
                ]
            }
        }
    ]
}
```

**参数说明**

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| update\_records | Object[]([UpdateRecord](#updaterecord)) | 是 | 由需要更新的记录组成的 JSON 数组 |

**返回示例**

```json
{
    "errcode": 0,
    "errmsg": "ok",
    "update_records": [
    ]
}
```

**参数说明**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| errcode | int32 | 错误码 |
| errmsg | string | 错误码说明 |
| update\_records | Object[]([CommonRecord](#commonrecord)) | 由更新成功的记录的具体内容组成的 JSON 数组 |

## 参数详细说明

### UpdateRecord

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| record\_id | string | 记录 ID，记录 ID 的获取方式如下所示 |
| values | Object | 记录的具体内容，key 为字段 ID ，value 详见([Value](#60594/value)) |

记录 ID 获取方式：
1. 通过 Webhook [新增记录](./60594.md)，在请求返回体中会返回新增记录的record\_id
2. 通过文档管理智能表格内容[查询子表API](./53109.md)查询记录的record\_id
3. 通过智能表格AI 字段获取记录ID，指令：获取记录 ID

### CommonRecord

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| record\_id | string | 记录 ID |
| values | Object | 记录的具体内容，key 为字段标题或字段 ID ，value 详见([Value](#60594/value)) |
