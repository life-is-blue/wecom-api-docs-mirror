用于删除指定智能文档中的数据表内容块。
注意
仅删除关联：此操作仅删除智能文档关联的数据表内容块 。
不可恢复：删除操作不可撤销，请谨慎操作。

 

请求方式：POST（HTTPS）
请求地址：https://qyapi.weixin.qq.com/cgi-bin/wedoc/smartdoc/delete_smartsheet?access_token=ACCESS_TOKEN

请求包体

{
    "docid": "DOC_ID",
    "block_id": "BLOCK_ID"
}

参数说明

参数类型是否必须说明
docidstring是智能文档的文档 id
block_idstring是要删除的数据表 Block ID

权限说明

  • 自建应用需配置到"可调用应用"列表中的应用secret所获取的accesstoken来调用（accesstoken如何获取？）
  • 第三方应用需具有"文档"权限
  • 代开发自建应用需具有"文档"权限

返回示例

{
    "errcode": 0,
    "errmsg": "ok"
}

参数说明

参数类型说明
errcodeint32错误码
errmsgstring错误码说明
