接口说明：调用该接口，可唤起选择器窗口，选择一个或多个文档。选中后返回对应文档的url。

调用前提：

必须先调用过wx.qy.login，且session_key未过期，开发者可调用checkSession 检查当前登录态。
当前成员必须在应用的可见范围之中，否则调用时会报“no permission”错误。
应用需具有文档使用权限，否则调用时会报“no permission”错误。

wx.qy.wedocSelectDoc(Object object)

参数

Object object
参数名类型必填说明
selectedFileNum是number选择文件的数量。1表示单选，大于1表示多选，上限为50
success否Function接口调用成功的回调函数
fail否Function接口调用失败的回调函数
complete否Function接口调用结束的回调函数（调用成功、失败都会执行）

返回结果

Object res
参数名类型说明
resObj返回信息
res.errMsgstring执行结果。"wedocSelectDoc:ok" 表示执行成功，否则表示报错信息
res.resultObj返回的数据
res.result.selectedFileUrlsArray<string>选择的文档的 url 列表。后续废弃，请使用selectedFileInfos
res.result.selectedFileInfosArray<object>选择的文档信息列表。企业微信版本 ≥4.1.8 才返回
res.result.selectedFileInfos[].urlstring选择的文档url
res.result.selectedFileInfos[].typeuint32选择的文档类型。0: 其他，3: 文档，4: 表格，5: 收集表，6: 幻灯片，7: 思维导图，8: 流程图，10: 智能表格

示例代码

wx.qy.wedocSelectDoc({
	selectedFileNum: 1,
	success: function(res) {
		var selectedFileUrls = res.result.selectedFileUrls;  // 后续废弃
		var selectedFileInfos = res.result.selectedFileInfos;
	},
	fail: function(res) {
		console.log(res)
	},
});

错误列表说明

res.errMsg说明
qy.wedocSelectDoc:ok执行成功
qy.wedocSelectDoc:cancel取消选择
qy.wedocSelectDoc:fail no session or expired没有调用 wx.qy.login，或者 session_key 已过期
qy.wedocSelectDoc:fail no permission无权限
qy.wedocSelectDoc:fail param error参数错误
qy.wedocSelectDoc:fail context error选择器异常
qy.wedocSelectDoc:fail not supported system version低系统版本不支持
