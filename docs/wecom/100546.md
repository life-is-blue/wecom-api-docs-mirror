# 监听 Wi-Fi 连接成功

## ww.onWifiConnected(callback)

> 兼容性：企业微信 iOS、Android 2.4.16 开始支持

### 功能描述

监听 Wi-Fi 连接成功。

```ts
ww.onWifiConnected(function(event) {
  console.log(event)
})
```

### 参数说明

#### callback: Function

**参数**

**event: Object**
