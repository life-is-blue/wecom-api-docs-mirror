可通过此接口，获取本企业的内部群信息，包括群主id、群创建时间以及所有群成员的id与加入时间。

权限说明

内部群中至少存在一个员工在授权范围内
应用类型权限要求
自建应用需具备「数据与智能专区权限」
代开发应用需具备「数据与智能专区权限」
第三方应用需具备「数据与智能专区权限」

请求方法
通过SDK调用，具体方式参考专区程序使用指引。

请求接口名：
get_group_chat

请求示例：

{
	"chatid":"wrNplhCgAAIVZohLe57zKnvIV7xBKrig"
}

参数说明：

参数必须说明
chatid是待查询的群id

 

此接口可以查询chatid对应的群信息，chatid可以从获取会话记录中获取到的chatid填充。只支持内部群和企业互联群。

返回结果

{
    "errcode": 0,
    "errmsg": "ok",
    "creator": "woAAAAAAA",
    "room_create_time": 1592361604,
    "members": [
        {
            "memberid": "woAAAAAAAA",
            "jointime": 1592361605,
			"type": 1
        },
        {
            "memberid": "woBBBBBBBB",
            "jointime": 1592377076,
			"type": 2
        }
    ]
}

返回字段说明：

字段名说明
errcode返回码
errmsg对返回码的文本描述内容
creatorchatid对应的群创建者，userid
room_create_timechatid对应的群创建时间
memberschatid对应的群成员列表
memberidchatid群成员的id，userid、external_userid、机器人id
jointimechatid群成员的入群时间
typechatid群成员的类型
1：员工
2：外部联系人
3：机器人

错误说明：

返回码说明
301052会话存档已过期
