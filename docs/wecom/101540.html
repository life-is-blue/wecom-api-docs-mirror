删除规则

该接口用于根据规则 ID 批量删除通讯录隐藏规则。

请求方式： POST（HTTPS）

请求地址： https://qyapi.weixin.qq.com/cgi-bin/contactrule/delete?access_token=ACCESS_TOKEN

请求包体：

{
  "rule_ids": [10001, 10002]
}

参数说明：

参数是否必须说明
access_token是调用接口凭证。仅通讯录同步应用的 access_token 可调用该接口
rule_ids是要删除的规则 ID 列表，最多支持 100 个

权限说明：

  • 仅允许通讯录同步应用调用。
  • 1分钟最多调用5次，1小时最多调用10次，1天最多调用60次。创建、修改、删除接口共用同一个频率

返回结果：

{
  "errcode": 0,
  "errmsg": "ok"
}

返回参数说明：

参数说明
errcode返回码
errmsg对返回码的文本描述内容
